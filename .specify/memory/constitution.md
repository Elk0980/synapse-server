# Конституция разработки Synapse

Версия: 1.0.0. Принята: 2026-09-30.

## I. Проверяемый результат
Для новой функции обязательны требования, план, задачи и свидетельства проверки по docs/spec-kit-policy.md. Код написан, тесты пройдены, подключено, проверено в рабочей системе и принято — разные состояния. Не заявлять последнее без доказательства.

## II. Единый процесс моделей
Любой ИИ-разработчик читает эту конституцию и AGENTS.md. Для внешних моделей передаётся тот же пакет. Фактическая модель и получение контекста проверяются отдельно; недоступность не маскируется. Не запускать конкурирующих авторов.

## III. Границы и разрешения
Поручение пользователя определяет владельца, компанию и разрешённую область. Один писатель на файлы и общий ресурс. Спецификация не выдаёт доступ, не разрешает сообщения, изменение прав, режимов ботов или развёртывание. Прямые инструкции пользователя имеют приоритет.

## IV. Переиспользование и изоляция
Использовать существующие модули и контракты. Отличия компаний задавать конфигурацией там, где поведение общее. Данные клиентов, секреты и переписки не добавлять в публичные спецификации. Не смешивать компании.

## V. Соразмерность
Для малых исправлений достаточно Spec-lite с целью, границами и реальной проверкой. Не создавать новые версии документов ради отчёта и не запускать модели ради галочки. Существующие AGENT-ECONOMY.md и правила проекта применять при наличии.

## Управление
Изменять конституцию по порученной задаче с пересмотром зависимых инструкций и проверкой CI. Никакая автоматическая проверка файлов не доказывает внутреннее соблюдение правил моделью. Ревью результата обязательно.
