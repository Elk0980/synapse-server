# Правила рилсов и роликов для сайтов

Версия списка: 1 (04.11.2026). Задача доски №66. Список собран из документов базы проекта: VIDEO_PREFLIGHT, STANDART_MATERIALOV, MEHANIKI_DVIZHENIYA, USTAREVSHIE_PRAVILA, REELS_SITE_STORY, REELS_CHARACTER_STORY, LAUNCH_REVIEW_20260924, а также из замечаний Влада по рилсам проектов alvi, avokado, palitra и synapse. Тексты документов в репозиторий не переносятся. Здесь только проверяемые правила и ссылки на источник.

Как читать:

- **Авто**: `да` — правило проверяет `check.py`; `частично` — скрипт проверяет измеримую часть, остальное смотрит человек или модель; `нет` — проверка глазами или по журналу монтажа (чем именно, указано в строке).
- **Статус**: `действует` или `отменено`. Если документы противоречат друг другу, действует последнее по дате решение Влада. Отменённые правила собраны в конце файла вместе с причиной.
- **Профиль**: `reel` — рилс 9:16 для соцсетей; `site-loop` — фон на сайте, который крутится сам (механики M1, M4); `site-scrub` — ролик, который двигается от прокрутки (механики M2, M3). Механики описаны в MEHANIKI_DVIZHENIYA.

## Противоречия между документами

- **О1. Палиндром.** STANDART_MATERIALOV §3 (23.08) требует палиндром. VIDEO_PREFLIGHT (29.08) запрещает реверс. MEHANIKI_DVIZHENIYA (29.08) разрешает палиндром для симметричного движения. Запись от 04.09 называет реверс запрещённым решением Влада. Действует запрет (R06).
- **О2. Вес.** STANDART_MATERIALOV: 600 КБ на блок и 1,5 МБ на обложку. VIDEO_PREFLIGHT: около 1 МБ на кусок хиро, 600 КБ и 350 КБ для блока. MEHANIKI_DVIZHENIYA: лимит по механике, у M2 — 300 КБ. Действует таблица механик и 350 КБ для блока на телефоне (R11).
- **О3. Палец в кадре.** Решение 01.11 в 15:19 («каждый сайт пролистывается») было выполнено кадром с пальцем. Решение в 15:53 палец убрало (R22).
- **О4. Кодек.** «webm основной» против «M2 и M3 только H.264». Действует разделение по механике (R12).
- **О5. Морф оптическим потоком.** VIDEO_PREFLIGHT предлагает морф для стыка. MEHANIKI_DVIZHENIYA ограничивает его позами человека. Это граница применимости, а не отмена (R10).
- **О6. Запас по краям у эталона персонажа.** STANDART_MATERIALOV §1 требует 5 %, §1.2 — 10 %. До уточнения Влада действует 10 %. Это правило для картинок; в проверку роликов оно не входит.
- **О7. Звук palitra.** Пробные ролики 24.09 сделаны без звука. Черновик брифа от того же дня предлагает рубрику с живым звуком сборки; бриф не согласован. До согласования для palitra действует «без звука» (R16). Политика звука palitra в `check.py` меняется только после того, как решение Влада записано в этот файл.
- **О8. Аккаунт генерации и лимит.** Запись 29.08 указывает один номер профиля и два ролика в окно 3–4 ч. Запись 01.11 — другой номер профиля и три ролика в окно около 5 ч. Это процесс генерации, а не проверка файла: перед генерацией проверять имя аккаунта. В скрипт не входит.
- **О9. «Без звука» для мастер-копии.** STANDART_MATERIALOV §3 требует мастер без звука. Рилсы avokado идут с голосом. Это разные профили: правило §3 относится к видео для сайта (R14), для рилса действует R16.
