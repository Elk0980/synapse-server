# Инструкции Claude для этого репозитория

Прочитай и соблюдай общие инструкции проекта:

@AGENTS.md

@docs/spec-kit-policy.md
@.specify/memory/constitution.md

Для разработки используй установленные навыки `.claude/skills/speckit-*`. Перед делегированием передай тот же процесс и ограниченную задачу; приёмку проверяй по результату, а не отчёту модели.

Для порученного фонового контроля и ожидания результатов применяй общее правило:

@docs/agent-monitoring-policy.md

Если собственная работа завершена, передай результат один раз, обнови базу знаний и отключи свои повторные проверки. Не дублируй контроль координатора и не расходуй токены на пустые циклы. При блокировке используй реальное расписание, а не обещание в сообщении.
