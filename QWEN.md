# Инструкции Qwen Code

Перед любой разработкой прочитай AGENTS.md, docs/spec-kit-policy.md и .specify/memory/constitution.md.
Выполняй общий процесс Spec Kit: требования → план → задачи → реализация → проверка соответствия.
Команды находятся в .qwen/commands/speckit.*.md. Фактическую модель и провайдера проверять отдельно; название клиента их не доказывает.
