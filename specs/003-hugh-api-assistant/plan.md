# План
Исполнитель Codex: существующий Claude занят и недоступен, второй автор не запускается. Один checkout и один серверный писатель. Область: project-chat.js, новый hugh-api-assistant.js, тесты, настройки cabinet/project-chat.js и данная спецификация.

SQLite: отдельная политика комнаты и метка маршрута нового задания. Настройки сохраняются существующим owner/CSRF endpoint. JSON-решение модели валидируется отдельным модулем; ответ и task/note записываются одной существующей транзакцией. Новые API-задания используют existing fallback/budget. Локальные worker-компании не переключаются незаметно — включение отклоняется при конфликте.

Контракт решения: action reply/ignore/escalate; text; task.title, task.note, task.existingTaskId. Никаких команд, произвольных companyId или других операций. Эскалация использует project_chat_tasks и notes своей комнаты. UI: переключатель и компактный рабочий контекст.

Уточнение владельца: уведомления в Telegram и кабинете. Дополнительная область того же исполнителя: hugh-owner-alerts.js, ops/chat/project-chat-bridge.js и server.js. Очередь уведомлений персистентна; мост использует только уже настроенный TELEGRAM_OWNER_ID. Сообщение модели не выбирает получателя. Контроль задержек идёт независимо от занятого AI worker. Новое отдельное поручение о всеобщем диспетчере доски потребует продолжения поверх CRM-доски; этот шаг не выдаётся за запуск всех агентов.

Выпуск: CI, PR, штатное обновление и пересборка content; включение только требуемой комнаты, проверка текущих API. Откат: выключить режим; новые операции прекращаются, история/задачи сохраняются.
