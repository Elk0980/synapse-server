# Самостоятельные ответы Хью через API

## Цель и границы
Владелец включает для отдельной комнаты недорогого помощника. Он отвечает на новые сообщения через уже подключённые API, а сложные запросы заносит в существующий список задач для человека. Никакого периодического запуска Codex, новых ключей, исполнения команд или изменения файлов.

## Требования
- FR1: режим выключен по умолчанию; включение и рабочий контекст доступны только владельцу комнаты. Другие комнаты и старая очередь не меняются.
- FR2: новые сообщения запускают API, без обращения к подписке Codex даже при отказе API. Без входящих сообщений расходов нет. Существующие бюджеты, очередь и защита доставки сохраняются.
- FR3: простые вопросы получают краткий ответ по контексту. Нерелевантные сообщения допускают молчание. Боты не запускают ответные циклы.
- FR4: сложные действия создают задачу либо уточнение к открытой задаче этой компании. Сообщение с номером задачи формирует сервер только после записи. Модель не может закрывать задачи, менять цены, файлы, права или публиковать.
- FR5: недостоверный/некорректный результат не отправляется клиенту. Повтор обработки не дублирует задачу или ответ. Отказ API сохраняет запрос.
- FR6: актуальная передача хранится на сервере; клиентские факты и ключи не попадают в публичный репозиторий.
- FR7: о передаче задачи человеку владелец получает уведомление в личном Telegram и кабинете. При отсутствии ответа 60 секунд клиент получает статус, владелец — сигнал. Через 15 минут без движения задачи — одно дополнительное уведомление. Срок выполнения не выдумывается. Проверка сроков не вызывает LLM. Неизвестная доставка не повторяется автоматически.
- FR8: владелец может проверить реальный API без отправки клиенту и тестовое уведомление самому себе. Эти действия недоступны участникам.

## Приёмка
Тестами проверить владельца, изоляцию, отсутствие primary /reply, простой ответ, задачу, уточнение, повтор, неверный JSON, выключение и отсутствие новых сообщений. Отдельно подтвердить рабочую модель и её ответ; тесты не означают выпуск.
