# Свидетельства

08.10: действующая доска проектов лично прочитана в ЛК, она учитывает задачи и этапы, но не захватывает общий ресурс. Запрос текущей занятости отправлен конкретному активному исполнителю общего сервера по новому поручению Влада. Свобода/production-размещение пока не подтверждены.

Локально прошли 39 проверок: шесть проверок очереди, существующие проверки доски и интеграционные проверки прав CRM/content, включая запрет доступа клиенту и записи без CSRF. Ещё две проверки интерфейса очереди прошли отдельно. Проверены два независимых подключения к SQLite, сохранение после повторного открытия, устаревшая аренда, FIFO, идемпотентность, CAS и неизменяемый журнал. `node --check` для server.js/tasks.js, `git diff --check` и `python tools/spec-kit/gate.py check` прошли. Пути и запуск очереди добавлены в существующий CI.

Это локальная проверка. Очередь не считается размещённой, а все исполнители — зарегистрированными до личной проверки production и фактических подтверждений участников. Внешние SSH-команды очередь сама не блокирует.

Интерфейс лично проверен в браузере с тестовой SQLite: unknown без кнопки занятия → подтверждение тестовой среды → один holder с именем/чатом/областью/временем → завершение с основанием → журнал сохраняет контекст исполнителя и таймер15мин при пустой очереди. Искусственная среда была явно отмечена. В production существующая доска сохраняет отдельную задачу запуска механизма; она не выдаётся за готовую аренду ресурса. Публичная инструкция AGENTS дополнена обязанностью регистрации и проверкой участия после размещения.
