# Метки формата и ОВП в статистике

Цель: общие фильтры статистики используют сохранённые метки доказанной карточки компании, без догадок по тексту или адресу. Процесс Spec Kit 1.0.0; владелец root.

- FR-001 Добавить nullable `format` (post/story/reel/carousel) и `ovpRole` (reach/affection/sale) в crm.posts.
- FR-002 Читать только по уже доказанному autopostingId той же компании; конфликт/усечённые receipts/нет связи/неизвестная метка возвращают null.
- FR-003 Один ограниченный batch SELECT метаданных, без изменения данных, сборов или новых API запросов.
- FR-004 Старые базы без meta и отсутствие модуля автопостинга совместимы. Не раскрывать остальные meta/личные сведения.

Приёмка: доказанная связь даёт метки; чужая/спорная/неподтверждённая — нет. Неизвестное не заменяется значением по умолчанию, чтение не меняет total_changes. Без production/live API/секретов/сообщений/прав/commit/push/deploy.
