# Компактный первый экран каталога

## Цель
Посетитель каталога быстрее видит товары: убрать ошибочно унаследованную высоту видеоблока. Основа — origin/main 6cc7597. Единственный писатель — lead_flow_review; root выполняет review и выпуск.

## Требования и приёмка
- FR-001: только `body[data-page="catalog"]` получает hero с автоматической высотой, без минимальной высоты видео, с отступами 16px сверху / 12px снизу. Следующий section имеет 20px сверху; пустой actions скрыт. h1 — clamp(32px,4vw,48px), margin 0 0 12px.
- FR-002: главная, цены, данные, фотографии, карточки, фильтры и заявки не меняются. CSS применим к каталогу и его категориям, включая ширины 320/390 px.
- FR-003: только 11 HTML каталога получают новую query-version stylesheet. Остальной HTML не меняется.
- SC-001: существующие проверки страниц, карточек, каталога и покупки проходят; новые тесты, повторяющие CSS, не создаются.
- SC-002: diff ограничен CSS, версиями stylesheet, актуализацией существующей проверки версий и spec/evidence. Браузерная приёмка и live остаются за root.

## Границы
Без редизайна главной, новых зависимостей, серверных изменений, изменения прав, отправок или публикации этим исполнителем. Исправление не обещает размещать любую карточку целиком в любой высоте viewport.
