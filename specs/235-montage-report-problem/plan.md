Один автор — Codex, отдельная ветка от main c3870631. Обязательная зависимость: узкое исключение для problems в ops/content/server.js и сквозной тест, потому что обычный POST proxy требует edit и блокирует view-only (зафиксировано в №286).

Переиспользовать INSERT обычных tasks рядом с reel-requests.taskFor и существующую BEGIN IMMEDIATE транзакцию. Добавочная таблица reel_problem_reports содержит постоянный ключ повтора и связь с задачей. Схема создаётся IF NOT EXISTS, существующие таблицы/данные не переписываются. Полная карточка получает problemReports; прежние поля сохраняются.

Форма отдельная, не перерисовывает редактирование ролика. Черновик и clientRequestId живут в состоянии до подтверждённого ответа, номер отправленной задачи читается также из карточки. Ошибки не очищают ввод. Служебный ключ в браузер не попадает.

Проверки: unit + настоящий CRM + content proxy, DOM, синтаксис, gate check/converge, CI. Выпуск CRM/content и двух статических файлов по существующему порядку с проверкой занятости production отдельно; локальный план не захватывает ресурс.
