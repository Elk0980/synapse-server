# Единый процесс ИИ-разработки

## Цель
Подключить GitHub Spec Kit к Synapse с общими правилами для всех моделей и проверяемыми границами внедрения.

## Требования
- FR-001: установить официальные интеграции Codex, Claude Code, Qwen Code с зафиксированным происхождением и лицензией.
- FR-002: все входные инструкции ссылаются на один процесс и конституцию, существующие правила сохраняются.
- FR-003: пакет для внешних исполнителей содержит правила, spec/plan/tasks и контрольные суммы; никаких секретов и автоматических отправок.
- FR-004: локальная и CI-проверка обнаруживает пропавшие/изменённые официальные файлы и отсутствие спецификации в PR. Малые правки допускают явное обоснование.
- FR-005: отчёт отличает установленные интеграции от реально проверенных запусков и защищённого обязательного CI. Не обещать автоматическую доставку в старые чаты.

## Приёмка
- SC-001: gate проходит на комплекте и отклоняет повреждённый комплект.
- SC-002: PR без Spec/Spec-lite отклоняется; существующий полный комплект принимается; выход за specs запрещён.
- SC-003: пакет содержит актуальные файлы; изменение требования меняет его SHA256.
- SC-004: инструкции общего процесса не разрешают менять права, включать клиентские автоответы или смешивать компании.

## Границы
Не изменять production, клиентские прайсы, провайдеров, ключи и занятые checkout. Не подменять серверную координацию документами.
