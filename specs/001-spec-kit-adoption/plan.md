Владелец: текущий чат по прямому поручению Влада. Исполнитель: Codex; действующий подходящий Claude Opus 5.5 High для этой задачи не подтверждён, старые сессии не возобновлять.

Область: `.specify`, `.agents/skills/speckit-*`, `.claude/skills/speckit-*`, `.qwen/commands/speckit.*`, входные инструкции, `tools/spec-kit`, собственный workflow, документация и эта спецификация. Один писатель, отдельная ветка codex/spec-kit-adoption.

Официальный specify-cli устанавливается в изолированное локальное окружение. Общие ресурсы и три интеграции устанавливаются штатными init/integration install, без замены существующего приложения.

Проверяющий скрипт Python standard library: проверка манифестов upstream и инструкций, безопасное чтение спецификации, проверка PR body из event JSON без shell-интерполяции. Пакет для любого внешнего агента выдаётся в stdout, не отправляется самостоятельно.

Проверки: unittest для отрицательных сценариев, штатный check_prerequisites, gate, GitHub CI. Изменение прикладных сервисов не требуется.
