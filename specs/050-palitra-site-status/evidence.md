## Существующий способ без кода — проверен, его нет
- HTTP `/content/sites` (`ops/content/server.js`): `GET` — список и карточка, `POST` — только новый пустой черновик (`companyCode,name`), `DELETE` — только управляемый черновик. Метода смены статуса нет.
- Кабинет (`sites/synapse/cabinet/sites.js`) только группирует по `publicationStatus`: «Чистовые сайты» и «Черновики».
- Правка одной строки `LEGACY_SITES` не помогает: `INSERT OR IGNORE` не обновляет существующую строку. Это подтверждено контрольным прогоном ниже.
- Штатный механизм — одноразовая миграция с отметкой в `site_migrations`, как `avokado_publication_20260915` и `alvi_publication_20260915`. Патч повторяет его.
