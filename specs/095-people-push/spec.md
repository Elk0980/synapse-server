# Люди и уведомления — задача №35

Владелец реализации Codex — Люди и уведомления; проверяющий Claude. Процесс Spec Kit 1.0.0.

- FR1. Исполнитель использует существующий auth_users и company_team_members. Доступ создаёт/переводит владелец, без автоматического приглашения. Существующие данные сохраняются.
- FR2. Назначение person:<auth_users.id> связывает человека с задачей либо веткой; совпадение имени не выдаёт доступ. API проверяет актуальную компанию и права для старых задач, новых задач и открытых сессий. Человек меняет только статус разрешённой задачи с revision CAS.
- FR3. Отдельная страница /cabinet/people.html работает на 390px и ПК, вход по прежней сессии; страницу доски №26 не менять. ЦКП из описания, этапы, процент по подзадачам либо подтверждённым этапам.
- FR4. Web Push по явному действию человека и Telegram-дубль через существующую персональную привязку и явно настроенного бота компании. Opt-in, защита чужих компаний/подписок, durable очередь, отсутствие слепого повтора UNKNOWN, выключенная по умолчанию доставка.
- FR5. По ответу Claude №58: начальные настройки — пятница, минимум7 уникальных согласованных публикаций плана следующей недели пн–вс в timezone проекта. Утром «Согласовано M из7, на согласовании N», вечером при M<7. День, порог, часы, метрика и интервал настраиваются по проекту; правило и доставка исходно выключены, предпросмотр не отправляет.
- FR6. Старые данные/права не мигрируют по имени. Владелец явно назначает старые задачи и переводит существующего редактора в узкую роль. Ошибка сохраняет поля формы, SW не кеширует личные ответы и проверяет текущую сессию перед показом текста.
- FR7. content-plan.approve даёт человеку право согласовывать текущие версии плана только своей компании, без owner/автопостинга. Использовать прежние media_mentor решения, версии и историю. Решение привязано к текущим брифу/плану и записывается от реального userId.

Приёмка: тесты ACL/CSRF/отзыва прав/изоляции/подзадач, queue restart/dedupe/uncertain/opt-out, пятница/timezone/6↔7/revisions, UI390 и unsafe payload.
