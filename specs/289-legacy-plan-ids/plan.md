# План / Plan

Один автор кода: Codex в codex/legacy-plan-ids-289, база49dad639. Разрешённая новая область:
ops/crm/media-mentor-legacy-ids.py и .test.js, эти Spec-документы и одна строка CI,
включающая тест. Рабочие модули CRM/кабинета, API и схемы не меняются.

Python3 stdlib sqlite3 читает закрытый backup. Настоящая схема для синтетического теста
создаётся существующими createMediaMentor/createMediaMentorTransfer под Node24.
Тесты вызывают CLI отдельным процессом и сравнивают полный снимок до/после.

Manifest закрепляет company/revision/SHA сырого JSON, все выбранные позиции и будущие ID,
схему и хеши связанных company-scoped таблиц. JSONDecoder находит границы токенов,
поэтому apply не сериализует заново остальные данные. CAS по company_id+исходному plan,
BEGIN IMMEDIATE и SQL authorizer не допускают других изменений. Архив в helper отсутствует.
