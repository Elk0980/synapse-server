# Проверка спецификации

- [x] Пользовательский результат и границы описаны.
- [x] Пустое состояние и недоступность различаются.
- [x] Авторизация и недоверенные callback проверяются отдельно.
- [x] Нет новой БД задач и угадывания проектов.
- [x] Разработка отделена от выдачи доступа/публикации.
- [x] Неизвестные production значения проверяются при запуске.
- [x] Каждому FR соответствует локальная проверка либо явно отложенная live проверка.
