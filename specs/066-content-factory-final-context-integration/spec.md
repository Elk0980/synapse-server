# Контент завод — связанный контекст и просрочки

Процесс Spec Kit1.0.0. Влад разрешил параллельную реализацию полной схемы01.10.2026. Root единственный автор существующих ops файлов; исполнители064/065 пишут только выделенные новые модули.

## Сценарии и требования

- FR-001. При новом запуске сервер сохраняет ограниченную проекцию качества сохранённой статистики прошлого календарного месяца. Она доступна только владельцу или при analytics.view. Браузер не задаёт статистику, права не расширяются, живой сбор не запускается. Ошибка/отсутствие данных не блокирует черновой план. Ранний повтор ключа возвращает прежнее задание до нового чтения статистики.
- FR-002. Снимок хранит только одобренный bounded DTO064. В prompt попадают только площадка, coverage/confidence/freshness и фиксированные безопасные редакционные рекомендации/ограничения. Не передавать числовую статистику, аккаунты, URL, raw labels, upstream errors или причины сборщика. Не делать вывод о причинности или успешной теме по одной публикации. Старые задачи совместимы.
- FR-003. Библиотека исходников в prompt содержит метаданные, не просмотренное моделью медиа. Ссылка на сырой/text/неподходящий для публикации исходник сопровождается предупреждением о подготовке материала. Выбор исходника не означает готовность, прикрепление, право использования или публикацию.
- FR-004. Настоящие просроченные текущие задачи согласования из065 читаются закрытым серверным маршрутом по service-key без browser identity. Данные только своей текущей карточки, без одобренного/архивного/опубликованного согласования. Реальные срок/ответственный; пустое имя показывается как неназначенное, timezone fallback обозначен.
- FR-005. Существующий runner.sync передаёт факты просрочки в существующую очередь владельца с идемпотентным eventKey. Не добавлять отдельный таймер, права или канал сообщений. Потеря ответа/рестарт не дублируют уведомление. Ошибка проверки просрочки не мешает сохранению и подтверждению уведомлений генерации; остановка прерывает запросы.

## Приёмка

Синтетические SQLite/HTTP пробы: права/ранний replay/ошибка saved-read/immutable snapshot/prompt privacy; готовый и сырой источник; закрытый маршрут key/identity/body, runner.sync повтор/остановка/сбой независимой ветки. Проверка SHA/diff и общая QA после остановки авторов. Без production/live API/клиентских сообщений/секретов/прав/commit/push/deploy.
