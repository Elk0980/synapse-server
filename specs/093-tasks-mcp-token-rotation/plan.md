## Установка

Runbook не подменяет свежую проверку сервера и блокировки. После приёмки: проверить право/проект/единственного писателя, privately сравнить effective config с runtime, выбрать действительный env источник, поменять только токен, адресно recreate, проверить old401/newAPI и неизменность остальных контейнеров. Новое значение вводит владелец в обоих клиентах. Если транспорт управления/личное действие недоступно, сохранить конкретный handoff, не обходить отказ и не считать шаг установленным.
