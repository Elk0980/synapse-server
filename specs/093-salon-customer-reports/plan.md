# План

Один автор Codex в изолированном worktree. CLI Claude не авторизован; конкурирующие модели/писатели не запущены. Штатный браузер CUA после восстановления работает: разрешённые обычные отчёты двух филиалов реально прочитаны. Исторический защитный отказ Sky и запреты чтения ключей не обходились.

Реализованы чистая математика полной истории, отдельный адаптер ограниченных нативных UI-агрегатов, read-only HTTP и общий мобильный renderer. Существующие marketing first-touch когорты не переопределяются. Native агрегат не преобразуется в вымышленные клиентские/платёжные строки. Числа источников и proof хранятся приватно, публичный Git содержит код и синтетические проверки.

Подготовлены классификатор входа и отдельный store/ingestion для статистики приложения. Компания определяется доверенным серверным маршрутом, body не может её подменить. Приём требует точный Origin и rate limiter; дата сбора сохраняется между перезапусками. Клиентский mount не включается автоматически в рабочем кабинете; реальная customer entry и существующее разрешение аналитики проверяются при установке. Новые ссылки площадок не публикуются до проверки настоящей точки входа.

Точечные подготовщики применяются к свежей публичной основе с SHA-проверкой. Истинная серверная основа берётся отдельно: native production может отличаться от старого ops/content/server.js. Студийные нативные чаты/attachments, приватное хранилище/публикатор, source tracker, live роли и уведомления ещё требуют соединения с актуальным backend и native приёмки.

Никаких OAuth, новых ключей/регистраций/прав/писем/записей YCLIENTS. Установка после свежего единственного писателя, exactbase, backup и конкретного rollback. Действующий ежедневный08-00 переиспользуется, новые дубли не создаются.
