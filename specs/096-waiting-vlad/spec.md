## Требования

- FR1: наверху главной владельца список «Ждут Влада». Условие: blocker или nextAction начинается с «ждёт Влада»/«ВОПРОС → Влад», без учёта регистра; либо фактический исполнитель — Влад. Пустой список скрыт. Строка показывает №, проект, требуемое решение и достоверное время начала ожидания.
- FR2: в карточке ответ создаёт комментарий от Влада с префиксом «ОТВЕТ:». Кнопки Да/Нет создают только такой комментарий; выпуск, слияние и иные внешние действия не запускаются. Снять ожидание очищает явно ожидающий blocker и/или удаляет только маркер ожидания из nextAction (API next_step), сохраняя текст самого действия. Один запрос с revision, без изменения исполнителя и неотмеченных полей. Ответ и снятие — отдельные действия. Неизвестная отправка не повторяется автоматически, новый черновик не стирается поздним ответом.
- FR3: свёрнутая памятка «Как читать доску»: Цель → Модули → Задачи → Этапы. Четыре подтверждённых этапа дают по25%; задача со статусом done имеет100%. Это не меняет сохранённые подтверждения и не приписывает приёмку Владом.
- FR4: цель определяется префиксом «Цель · », модуль — «Модуль · ». Префикс модуля не показывается пользователю; прежние направления сохраняют совместимость. Состав модуля: дочерние задачи, номера из строки «Состав: №…» и задачи с отдельной строкой «Модуль №N» в описании, только доступные задачи того же проекта, без дублей и бесконечных циклов. Цель и модули исключаются из счётчиков задач и «Сейчас». cancelled не показываются и не участвуют в среднем; доступные активные потомки отменённого родителя сохраняются.
- FR5: цель показывает общий прогресс и «Сейчас строим: … → потом: …». Начатые модули показывают ЦКП, ведущего, принимающего и средний прогресс состава. Крупные карточки показываются только для начатых модулей. Не начатые перечислены одной компактной строкой «Дальше по плану» без повторных крупных карточек. Карточка начатого модуля показывает все его доступные задачи, включая вложенные, с собственным процентом и текстом этапа; полный состав остальных доступен при открытии модуля. Общий процент цели — среднее процентов её модулей с равным весом каждого, включая пустые с0%; формула поясняется рядом.
- FR6: «Сейчас в работе» показывает исполнительские задачи с модулем или «вне цели», четыре отметки и этап текстом. Отсутствующие данные не превращаются в подтверждение готовности.
- FR7: старые и новые задачи, ссылки, подзадачи, черновики, прежняя расширенная карточка и клиентская сторона сохраняются. Обновляются версия ресурсов и все прежние owner-точки входа; возврат/восстановление страницы не стирает ввод. Desktop и390px должны быть проверены; настоящая визуальная проверка отделяется от JSDOM.
