# Правила рилсов и автопроверка каждого ролика — задача доски №66

Владелец реализации: Claude (агент рилсов). Ревьюер: Codex. Процесс Spec Kit 1.0.0. Поручение Влада 04.11.2026: правку, сделанную один раз, применять ко всем роликам и проверять каждый ролик на прежние замечания.

## Цель

Свести правила монтажа из разных документов в один список с источниками. Сделать скрипт, который проверяет каждый ролик до показа Владу.

## Сценарии

1. Монтажёр собрал рилс → запускает `check.py --profile reel --project <код>` → получает ✔/✘/⚠/— по каждому правилу и список ручных проверок → прикладывает отчёт к задаче ролика на доске. Ролик с ✘ Владу не показывают.
2. Видео для сайта (петля или ролик под прокрутку) проверяется по механике: вес, кодек, шов, реверс, события, ключевые кадры.
3. Влад даёт новое замечание → в тот же день появляется правило в RULES.md (и проверка, если её можно измерить) → все ролики в работе проверяются заново.

## Требования

- FR1. `tools/reels-check/RULES.md`: не меньше 15 правил. У каждого правила есть id, проверяемое действие, источник (документ или замечание, дата, код проекта), признак «Авто» (да / частично / нет и чем проверять) и статус. Отменённые правила и противоречия перечислены отдельно, действует последнее решение Влада. Палиндром: действует запрет.
- FR2. `tools/reels-check/check.py <video> --profile reel|site-loop|site-scrub [--mechanic M1..M5] [--json]` на ffprobe/ffmpeg проверяет: разрешение и ориентацию по профилю, частоту кадров, увеличение и кроп по `--source`, вес по лимиту механики, звук по профилю и проекту, шов петли (≤3 ✔, до 8 ⚠, больше ✘), реверс и пинг-понг, счёт событий по методу MEHANIKI_DVIZHENIYA, ключевые кадры для scrub, пустые кадры в начале, титры по файлу. В отчёте указаны время или кадр. Код выхода 1 при любом ✘.
- FR3. `tools/reels-check/test_check.py` (unittest) генерирует ролики ffmpeg: палиндром ловится, петля с ровным швом проходит, лишний вес ловится; проверяется и связь id в скрипте с RULES.md.
- FR4. README: запуск, зависимость от ffmpeg, порядок «замечание → правило в тот же день → прогон по всем роликам в работе», отчёт прикладывается комментарием к задаче ролика на доске.

## Приёмка

Тесты проходят локально. `python3 tools/spec-kit/gate.py check` проходит. В RULES.md нет имён людей (кроме Влада), телефонов, адресов, переписки, ссылок на частные диски и секретов.

## Ограничения

- Изменяются только `tools/reels-check/**` и `specs/100-reels-check/**`. Не мержить, не деплоить, не публиковать, не писать людям.
- Прогон по реальным роликам alvi, avokado и palitra не входит в этот PR: ролики лежат на Google Диске, доступа из среды разработки нет. Шаг 3 приёмки задачи №66 остаётся открытым.
- Правила, которые нельзя измерить по файлу (лицо под титрами, лист персонажа, палец, личные данные, цена), скрипт не проверяет. Он выгружает кадры и перечисляет такие правила для просмотра.
