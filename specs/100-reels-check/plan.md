# План

Ветка `claude/reels-check-20261104` от `origin/main` (fb59836). Один писатель — Claude (агент рилсов). Файлы: `tools/reels-check/{RULES.md,check.py,test_check.py,README.md}`, `specs/100-reels-check/*`. Существующие модули и контракты не меняются. Миграций, API и прав нет.

1. Источники — документы базы проекта (копии на Google Диске владельца, чтение) и журнал рилс-чатов. В репозиторий переносятся только формулировки правил и ссылки на документ и дату. Имена клиентов, переписка и адреса не переносятся.
2. `check.py` — один файл, Python 3 + numpy, внешние процессы ffprobe и ffmpeg. Кадры декодируются в оттенках серого шириной 160 px. Профили: `reel`, `site-loop` (M1, M4), `site-scrub` (M2, M3). Таблица звука по проекту и лимиты веса — константы со ссылкой на правило.
3. Тесты на синтетических роликах ffmpeg (testsrc, color, geq, reverse, noise, drawbox). Если ffmpeg нет, видео-тесты пропускаются, тесты правил и титров выполняются.
4. Отдельный CI workflow в этот PR не добавляется: разрешённая область — только два каталога. Подключение тестов к CI — отдельная задача.

Проверки: `python3 -m unittest discover -s tools/reels-check -p 'test_*.py'`, `python3 tools/spec-kit/gate.py check`, проверка diff на файлы вне области.
