# Редактор прайса Palitra: фото не «пропадают» при прокрутке

Процесс Spec Kit 1.0.0. Прямое поручение Влада 02.10.2026 19:39:53 (correlation eva-palitra-varvara-20261002-796e769a-…). Замечание Варвары 19:36 (mid 274679): «Пропадают фото карточек товаров при прокрутке»; раньше 18:49 — «Карточки товаров отрывками пропадают. Где-то есть, где-то нет». Исчезновение данных и сбой сохранения не установлены. Исполнитель — Claude, единственный автор. Номер 086: в `main` последний 084, 085 занят в двух ветках `origin`.

## Причина (установлена)
- `sites/synapse/price-render-palitra.js` выводил `<img loading="lazy">` без `width`/`height`; правило редактора `.pc .price-card__photo { max-width:100%; height:auto; aspect-ratio:4/5 }` не задавало ширину. До загрузки у ленивого фото нет внутреннего размера → ширина 0 → высота 0.
- Редактор показывает все 303 позиции одной лентой (раздел цветов включён, фото 720–1290 × 1280–1600). При прокрутке каждое догружаемое фото вырастало с 0 до ≈385 px и сдвигало всё ниже: на локальном стенде (Chromium, 390×844, DPR 3, снимок прайса 17.09) высота страницы во время прокрутки росла с 79 954 до 128 849 px. Без привязки прокрутки (scroll anchoring; в мобильном Safari её поддержка не подтверждена) видимые карточки уезжают — фото «пропадают» и «где-то есть, где-то нет».

## Требования
- FR-001: место под фото резервируется до загрузки: `width:100%` и `aspect-ratio:4/5` в CSS редактора, `width="800" height="1000"` в разметке; пустое место — светлый фон.
- FR-002: ленивая загрузка сохраняется (`loading="lazy"`), добавлено `decoding="async"`.
- FR-003: новый рендер подключается с версией (`price-render-palitra.js?v=20261002photos1`).
- FR-004: не меняются данные прайса, права, сервер, публичный сайт, другие страницы.

## Приёмка
- SC-001 `sites/synapse/price-editor-palitra-photos.test.cjs` — разметка и правило CSS (падает на коде до исправления).
- SC-002 существующие тесты редактора и импорта, `ops/content/client-price-access.test.js`.
- SC-003 локальный стенд Chromium (не Safari): высота страницы постоянна при прокрутке вниз/вверх; фото в видимой области загружены; синтетическое сохранение → перезагрузка показывает сохранённое.
- SC-004 (root/человек после выпуска): живой редактор на телефоне Варвары/Safari — критерии в отчёте.
