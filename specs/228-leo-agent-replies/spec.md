# 228 — Лео отвечает в чате кабинета через агента владельца

Источник: поручение владельца 07.11.2026 18:21 — «в чате ЛК отвечать как Лео; на „Лео, смонтируй…“ отвечать и работать».

## Проблема
У сервера нет ключа встроенного ИИ, поэтому на любое обращение в «Чатах» приходит «Ответ пока недоступен. Вопрос сохранён для проверки.». На «Лео, …» в общем чате ответа нет вовсе: сервер звал ассистента только по «Хью, …». Агент владельца (Claude в браузере владельца, его сессия и CSRF) не мог ни найти такие запросы, ни ответить от имени персоны.

## Сценарии
1. Сотрудник пишет «Лео, смонтируй рилс» в общем чате (или в личном чате с владельцем, или владелец — в своём логе с Хью). Сразу получает «Лео получил запрос и ответит здесь.» (автор «Лео»).
2. Агент владельца читает `agent-inbox` и видит этот запрос; после ответа запрос из inbox уходит.
3. Агент публикует ответ `agent-reply`; в ленте он подписан «Лео» и оформлен как ответ ассистента; его видят все, кто читает комнату.
4. Запрос к Лео в чужом логе с Хью (владелец его не читает): ответ «Лео отвечает в общем чате компании: напишите там «Лео, …».» — честно, без обещания.
5. Хью без встроенного ИИ работает как прежде.

## Требования
- FR-1. `POST /content/people/team-chat/agent-reply?companyCode=` — только владелец системы (`role=owner`, компания в сессии), CSRF обязателен. Тело ровно из `{room, text (1–2000 после trim), persona: leo|hugh, clientId, replyTo?}`; лишние поля — 400.
- FR-2. Вставка: `user_id 0`, `author_name` «Лео · Claude» / «Хью · Claude», `kind agent-reply`, та же компания и комната. Комната проверяется той же функцией, что при чтении/отправке владельцем: чужие `dm:*` и `hugh:<другой>` — 403. Новых прав нет.
- FR-3. `replyTo` — сообщение человека той же компании и комнаты, видимое владельцу; иначе 403 (в т. ч. несуществующее — без подсказки о существовании).
- FR-4. Идемпотентность: повтор с тем же `clientId` и тем же содержанием возвращает то же сообщение (`created:false`); другое содержание — 409.
- FR-5. Если у `replyTo` есть запасной ответ (`pending`, `review_required`, `agent_pending`), его строка в истории остаётся, статус журнала — `agent_answered`; вопрос уходит из очереди проверки владельца; поздний встроенный ответ не добавляется.
- FR-6. `GET /content/people/team-chat/agent-inbox?companyCode=&persona=leo|hugh&since=` — только владелец: сообщения людей компании в комнатах, которые владелец читает (общий, свой лог с Хью, личные чаты с владельцем), обращённые к этой персоне по той же логике, что вызывает ответ в чате (`team-chat.addressedTo`: «Имя, …» в начале или «@Имя»; в своём логе с Хью — Хью; названы оба — первый; простое упоминание не считается), только обычные сообщения (команды «Хью, поставь задачу / сделай …» и уточнения по задаче ведёт поток задач), без ответа агента и без ответа встроенного ИИ (`approved`, `refused`), не старше 7 дней, `id > since`, до 50 по возрастанию; `nextSince` для продолжения.
- FR-7. Запасной ответ: обращение «Лео, …» / «@Лео» при недоступном встроенном ИИ — «Лео получил запрос и ответит здесь.» (автор «Лео», статус `agent_pending`); комната, которую владелец не читает, — переадресация (`agent_redirect`). Хью — как раньше. Упоминание без обращения ответа не вызывает.
- FR-8. Кабинет («Чаты», «Хью · личный чат», отдельный team-chat.html): «Лео · Claude» / «Хью · Claude» подписаны «Лео» / «Хью», стиль ответа ассистента; статусы запасного ответа понятны («Ждёт ответа Лео», «Ответ ниже»). Подсказки называют обоих. Класс `sbc-msg--leo` получает тот же стиль, что ответ Хью (одно правило CSS, без изменения размеров) — вёрстка 390/1440 не меняется.

## Приёмка
`ops/content/team-chat-agent.test.js`, дополнения `sites/synapse/cabinet/chats.test.cjs` и `team-chat.test.cjs`, полные наборы `ops/content` и кабинета без новых падений, `gate.py check`.

## Ограничения
Без выпуска на сервер, без изменения живых данных, прав и ключей. Сам агент (кто и как часто читает inbox) этим PR не запускается: маршруты только дают ему законный путь. Ответ агента не проходит фильтр встроенного ИИ — за содержание отвечает владелец, от чьего имени работает агент.
