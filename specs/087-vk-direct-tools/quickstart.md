# Quickstart: локальная проверка без рабочих ключей

Process: Spec Kit 1.0.0. Среда: Node 24 с `node:sqlite`, Python для Spec Kit. Код, локальные тесты, CI, развёртывание и рабочее подключение — отдельные этапы; фактические результаты записываются в evidence.md.

1. Работайте в изолированном checkout ветки `087-vk-direct-tools`. Прочитайте spec.md и plan.md. Не открывайте runtime env, секреты и клиентские переписки.
2. Запустите целевые тесты с синтетическими токенами и подменённым VK transport. Ни один тест не должен менять рабочее сообщество, отправлять сообщения или обращаться к OAuth-выдаче.
3. Проверьте отрицательные случаи: другая компания/роль, отсутствие CSRF, несовпадение типа токена/группы, устаревшая revision, изменившееся описание, неверный файл/URL загрузки, редирект, повтор requestId, обрыв после отправки и утечка секрета в ошибке.
4. Проверьте сохранность Onlypult: прежний канал публикаций, расписание и credentials не изменились при настройке/сборе прямой аналитики. Для ручного VK inbox не появляется автоматическая отправка.
5. В DOM-проверке смените компанию во время запроса: поздний ответ не меняет новый экран; токен, файл и preview очищены. Apply доступен только для соответствующего подготовленного намерения, а неизвестный исход не изображается успехом.

Целевые команды (для DOM-тестов нужен `jsdom@26.1.0` в обычном пути Node или `NODE_PATH`):

```powershell
node --test ops/crm/vk-*.test.js ops/crm/social-vk-direct.test.js ops/crm/social-stats.test.js ops/crm/social-onlypult-flow.test.js ops/crm/autoposting-onlypult-flow.test.js ops/content/vk-*.test.js sites/synapse/cabinet/vk-*.test.cjs
node --test ops/crm/social-stats-project-period.test.js ops/crm/social-stats-project-period-http.test.js ops/crm/social-stats-tags.test.js ops/crm/social-onlypult-analytics.test.js ops/crm/social-analytics-credentials.test.js ops/crm/social-analytics-evidence.test.js
python tools/spec-kit/gate.py check
```

Наличие команды здесь не означает, что она выполнена или прошла. Фактические результаты и ограничения фиксируются в evidence.md. CRM Dockerfile уже копирует `*.js`, новые модули входят в образ без изменения сборки.

## После отдельного согласования развёртывания

Следуйте [приватной настройке подключения](../../docs/vk-direct-tools.md). Сначала сохранение и проверка нужного назначения в выбранной компании; затем чтение состояния/аналитики. Изменение описания или обложки требует отдельного предпросмотра и явного применения. Рабочие ключи вводит уполномоченный владелец только в специальное поле приватного кабинета; не в тесты, чат, URL, devtools или сторонний сервис.

## Проверка отката

На фикстуре восстановите описание через новый rollback-preview и apply. При изменении текста другим администратором восстановление должно остановиться. Не объявляйте автоматический откат обложки по одним прежним URL: для него нужен доступный оригинал. Отключение прямого назначения не должно менять Onlypult и не отменяет уже выполненные операции VK.
