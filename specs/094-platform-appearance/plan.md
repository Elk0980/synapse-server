# План

Один писатель: сначала Claude Code Opus 5.5 / High в изолированной копии, затем личная проверка и завершение Codex. После сбоя соединения Claude работа продолжена Codex. Рабочая копия перенесена на D после заполнения C; модель и реальные изменения проверены отдельно.

Общий ранний контроллер `sites/synapse/platform-theme.js` сохраняет предпочтение `sb-theme`, слушает систему и storage, синхронизирует подписанные селекторы. `platform-theme.css` содержит семантическую палитру и ограниченные замены фиксированных цветов. `cabinet/workspace.css` использует эти переменные, направляет только контейнер меню rtl и задаёт узкую полосу; дети ltr.

Подключения: `cabinet.html`, `site-editor.html`, `price-editor.html`, `price-editor-palitra.html`, `miniapp.html`. Клиентская палитра предпросмотра остаётся в body редактора, тема применяется к его панелям. `cabinet/miniapp-host.js` передаёт контроллеру системную тему Telegram, сохраняя приоритет ручного выбора.

`cabinet/analytics.js` вычисляет точные включительные даты, задаёт 30d при инициализации, поддерживает 365d и custom. Dashboard получает допустимый period или только точные from/to; существующий сервер уже поддерживает явный диапазон. Бизнесданные и права не меняются, миграции отсутствуют.

Проверки: runtime-тесты темы, периодов, меню, существующих блоков аналитики и Mini App; проверки синтаксиса и diff; личный браузерный образец на вымышленных данных, включая мобильное меню и системную тему.

Установка: сначала свежая целевая база и подтверждение одного писателя, затем только UI-пакет и backup/rollback. Подготовленная аналитика PR456 остаётся отдельным этапом; не переносить её серверный код вместе с оформлением по умолчанию.
