# Данные

Content: ai_cost_samples по reservation_id — время, провайдер, состояние и оценка стоимости; расход не дублирует финансовый журнал. ai_economy_meta хранит начало наблюдения. ai_balance_snapshots хранит только безопасные суммы и время/версию, без ключа и тела ошибки. ai_economy_alert_state подавляет повторы одного состояния.

CRM: добавочное JSON-поле review в task_dispatch и неизменяемой истории. Вердикт passed/changes/unavailable, проверяющий провайдер/модель, расход и короткое замечание. Исторические задачи без проверки не объявляются проверенными.
