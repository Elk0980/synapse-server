# Проверка

Запустить node --test для новых hugh-economy.test.js и связанных бюджетных/провайдерных/dispatch проверок. Запустить python tools/spec-kit/gate.py check.

В рабочем ЛК: Настройки системы → Экономика ИИ, проверить баланс DeepSeek, время снимка, отдельно локальный лимит. Новая внутренняя текстовая задача должна показать две разные модели либо явное отсутствие проверки. Не отправлять тест клиенту; результат принимает владелец.
