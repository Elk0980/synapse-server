# Доска задач владельца — №26

Источник: прямое поручение Влада 03.11.2026 и описание/все комментарии задачи26. Комментарии19/20 заменяют первоначальный мобильный макет: компактная доска по проектам и продуктам, отдельная точка входа в существующий кабинет. Прототип Claude v6 описан в комментариях; исходник самого артефакта не получен.

## Требования

- FR1: все разрешённые проекты без обязательного выбора компании; сводка статусов, текущая работа и задачи без отчёта. Вкладки проектов и фильтр продуктов.
- FR2: компактные карточки в колонках Входящие / Запланировано / В работе / Готово; отменённые доступны отдельно. Desktop drag/drop меняет статус, мобильная доска прокручивается внутри без расширения страницы.
- FR3: панель задачи содержит чат, исполнителя, проверяющего, срок, статус, четыре независимых этапа с основаниями и датами, подзадачи, ссылки, описание, план, ход работы и комментарий владельца. Пустые поля не засоряют карточки.
- FR4: новая задача требует проект; продукт выбирается или создаётся. Поиск похожих задач/продуктов до создания, сервер требует явный force при совпадении. Приоритет, parent_id, product_id и chat_url обновляются через прежний реестр.
- FR5: таблица products и task.product_id; перенос временных продуктов с физической резервной копией до миграции. Существующие задачи, история, комментарии, данные и ссылки сохраняются. Старые API-клиенты продолжают работать.
- FR6: те же проверки владельца, доступов проектов и CSRF; auth/push не меняются. Новая доска приходит во все прежние входы владельца и поддерживает восстановление страницы и черновиков. Не-владелец использует прежний клиентский список.
- FR7: светлая/тёмная тема, мобильные размеры390×844/360×800, desktop1440px, доступность клавиатуры; PWA с отдельным стартом в задачах и иконками. Проверка реальной установки на iPhone — приёмка отдельно.

## Границы

Только код страницы/интеграция существующего кабинета, API задач ops/crm и необходимые тесты/документы. Нет изменения auth/push, MCP-коннектора, Caddy, сервера, реальных ключей и клиентских данных. Ветка codex/board-lk-20261103, PR без merge/deploy. Приёмщик Claude; дальнейший выпуск требует отдельного «да» Влада.

## Приёмка

Локальные тесты API, миграции, старых записей, изоляции и UI. Свидетельства и ограничения в evidence.md. Живые действия/скриншоты/установка не подменяются JSDOM-тестами; до реальной приёмки стадии connected/verified/accepted остаются неподтверждёнными.
