# Регулярная статистика YouTube
Процесс Spec Kit1.0.0. Общий модуль для выбранной компании ALVI/Авокадо; отдельный доступ статистики, не публикаций.

## Требования
FR001: отдельный зашифрованный читающий OAuth youtube.readonly/yt-analytics.readonly, без публикаций и создания доступов; no redirects, ограниченные тело/срок/отмена, без утечек.
FR002: обязательный exact UC channel ID; mine=true подтверждает единственный совпадающий канал, смена/отзыв/неопределённость доступа не оставляют ложный connected. Handle сам по себе не подтверждает идентичность.
FR003: данные Analytics разбираются по колонкам; отсутствующая/поздняя дата неизвестна, не0; Pacific с DST, аудитория lifetime отдельно от суточных дельт и просмотров.
FR004: Analytics views/engagedViews не смешиваются с DataAPI viewCount; границы методик привязаны к своему полю, минуты переводятся в секунды.
FR005: общий SQLite планировщик сохраняет backoff/аренду/ревизию; нет цикла повторов на каждом тике, retryable:false не ставится в очередь; исправления истории проверяются по возможностям конкретной платформы.
FR006: перенос точечный к свежим shared-файлам; ВК direct, Telegram, Onlypult, crmPeriod и content_revision сохраняются.
FR007: owner/company ACL, текущий точный binding/revision и origin endpoint, новый ответ другой компании не записывается. Настройки показывают правильное действие для восстановления доступа.
FR008: ежедневные точки и ошибки сохраняются; перезапуск и второй плановый цикл имеют отдельные доказательства. Код/фикстуры не live admission.

## Приёмка
SC001: локальные HTTP/SQLite/DOM проверки с искусственными данными подтверждают требования, включая redirects, задержку дня, backoff, revoked grant, channel scope и restart.
SC002: живой exact channel/access подтверждён и отчёт независимо сверён с YouTube Studio, без публикаций.
SC003: установленный единственный worker сохраняет состояние после рабочего перезапуска и во втором наблюдённом цикле.

## Ограничения
Google app/refresh token/каналы/production ещё не подтверждены. Общий сервер требует текущего подтверждённого окна и rollback. Другие источники и вся цепочка/экономика остаются в общей задаче; этот этап её не завершает. UI PR459 и отдельная поддержка YCLIENTS paused.
