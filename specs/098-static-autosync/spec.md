# Автовыпуск статики: условия ревью №25/544

Цель: выполнить два обязательных условия установки принятого PR518, сохранив его границы.

FR-1: публичные каталоги cabinet/brand доступны Caddy на чтение/проход (2775). Приватные state/backup/log/runtime каталоги не открываются.
FR-2: до публикации любого файла коммита все допустимые изменённые JS проходят настоящий node --check. Ошибка, недоступный checker или невозможность проверить JS останавливают весь batch; CSS/JSON/assets/version не публикуются частично.
FR-3: неудачный HEAD не повторяется автоматически; commit/deployed/time успешной базы не продвигаются. Следующий новый HEAD проверяется заново.
FR-4: сохраняются зелёный CI точного SHA, CAS живых файлов, белый список, запрет symlink/submodule, кабинетный HTML вне автоматической выкладки, проверка HTTP и восстановление собственных файлов.
FR-5: исправление не устанавливает daemon, не включает timer, не меняет ключи, бизнес-права, Docker/Compose/Caddy, legacy-sync и локальный checkout с правками.

Приёмка: Linux с настоящим node и flock — валидный batch публикуется; valid CSS + плохой JS не меняют ни одного live файла/версии, повтор того же HEAD не запускает проверку снова. Независимый Claude принимает новый head до установки. Сам smoke merge→HTTP выполняется отдельным PR527 после установки518.
