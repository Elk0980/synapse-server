# №98/99 — Контент → Подключения и Статистика

Поручение Влада 04.11 (ночная задача №98, подзадача №99, агент Е). Два экрана раздела «Контент» по контракту А
(`specs/098-content-shell/contracts/module-registry.md`): `content-connections` (`#content/connections`) и
`content-stats` (`#content/stats`). Только чтение уже сохранённого в ЛК; никаких запросов к площадкам, публикаций,
сообщений, новых прав или ключей.

FR1. «Подключения» показывает все площадки компании (Instagram, TikTok, YouTube, ВКонтакте, Telegram-канал, Telegram-бот,
MAX, 2ГИС, Яндекс Карты, Яндекс Директ, Яндекс Метрика, YCLIENTS, сайт) со статусом 🟢 подключено / 🟡 частично / 🔴 нет.
FR2. Статус считает сервер по факту: 🟢 — свежие (за 14 дн.) данные автоматического источника (Onlypult/API, счётчик ЛК,
заявки в CRM); 🟡 — есть настройка (аккаунт статистики, канал постинга, ключ сообщества), подтверждение владельца
из приватной настройки сервера, только ручные или старые данные; 🔴 — ничего нет. Ссылка из CRM сама по себе не подключение.
FR3. Ссылки — только публичное представление CRM (`companyPublicLinks`: `websiteUrl` и типизированные `socials`).
Нет ссылки — «Ссылки в CRM нет», без угадывания. В браузер попадают только http(s).
FR2a. Директ и Метрика (уточнение координатора 05.11): серверный признак — `external_stats` их источников или визиты сайта
с платной меткой Яндекса (cpc/yclid): за 7 дн. — 🟢, старее — 🟡. Без признака у Метрики — счётчик в локальных исходниках
опубликованного сайта компании, без сети (ревью 504): 🟡 «Подключено вне ЛК, не проверено системой». Ручная переменная
`CONTENT_CONNECTIONS_DECLARED` — дополнительный источник. Ничего нет — 🔴.
FR4. Ключи не расшифровываются и не выходят наружу: только «есть / нет», «проверен / не проверен».
FR5. Права: GET через `/content/crm/content-connections`, `autoposting.view` ИЛИ `analytics.view` в своей компании;
прокси контента и CRM проверяют компанию независимо. Чужая компания и только `crm.view` — 403; запись — 405.
FR6. «Статистика» переиспользует существующий `GET /social-stats` (`analytics.view`): сводная таблица по соцсетям
(подписчики, охват, просмотры, вовлечённость, источник) и вкладки Instagram / TikTok / YouTube / ВКонтакте / Telegram
с итогами периода и днями. Метка у каждой площадки: LIVE, РУЧНОЙ ВВОД, LIVE + РУЧНОЙ ВВОД или НЕТ ДАННЫХ.
Нет значения — «—», не ноль; охват и подписчики между площадками не суммируются.
