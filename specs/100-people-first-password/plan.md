# План

Владелец: Codex — Люди и уведомления; ревью Claude. Основа main с PR478.
Один писатель backend, отдельный исполнитель people UI; production не занят нами.
auth-store/passwords: хэш, срок, CAS смены и отзыв сеансов. company-team/people-http:
только владелец создаёт/сбрасывает временный доступ активного участника своей команды.
server: общий барьер до маршрутизации и отдельный CSRF-защищённый POST /content/password.
people.html/js: однократный показ результата, экран обязательной смены, без storage.
Миграция идемпотентна; VACUUM INTO приватного каталога рядом с БД и integrity/FK
проверка перед ALTER; :memory: не требует файловой копии. Откат только процедурой выпуска.
Проверки: реальный loopback HTTP, старые сеансы/аккаунты, backup+повторный запуск,
DOM и 390px; затем Spec Kit gate и CI. Никаких новых зависимостей.
