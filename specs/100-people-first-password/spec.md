# №87 — первый личный пароль

Владелец создаёт доступ в «Люди»: сервер выдаёт временный пароль один раз,
владелец передаёт его самостоятельно. Человек задаёт свой пароль перед работой.

- FR-001: криптографический временный пароль ≥12 символов, только хэш в БД,
  срок 72 часа; повторная выдача владельцем отменяет прежние сеансы и пароль.
- FR-002: до смены кабинет/API отвечают 403 «Нужно сменить пароль»,
  разрешены смена и выход; обновление страницы возвращает экран смены.
- FR-003: свой пароль ≥10 символов, отличается от временного; смена атомарно
  снимает ограничение и увеличивает session_version; старые сеансы недействительны.
- FR-004: добавочные must_change_password/temp_password_expires_at,
  резервная копия старой файловой БД проверяется до DDL; старые записи/права сохранены.
- FR-005: аудит TEMP_PASSWORD_ISSUED/PASSWORD_SET_BY_USER без значений;
  никаких писем/приглашений/уведомлений. Экран работает на 390px.

Приёмка: создание → временный вход → отказ кабинета/других API → смена →
вход своим, отказ временным; истечение/повторная выдача; сохранение старых пользователей.
Стоп: необходимость менять роли/права существующих пользователей → ВОПРОС → Claude.
Одна PR около 500 строк; без merge/deploy, серверной миграции и изменения доски.
