## Onlypult: что реально отдаёт API
`https://onlypult.com/dev/openapi.yaml` скачан 05.11.2026 (info.version 1.0.0). Схема `Post`: id, status (draft/scheduled/published/failed), content, title, profile_ids, publish_at, published_at, media, poll, error, is_story, is_reels, is_shorts, created_at, updated_at — поля ссылки нет. `url` есть только у публикаций аналитики (`/analytics/{id}/posts`), связи с заданием публикации контракт не даёт. Поэтому для площадок через Onlypult в чат уходит «опубликовано, ссылка недоступна (ID задания Onlypult …)»; подбор ссылки по времени/тексту не делается.
