## Официальная документация Telegram (сверено 02.10.2026, core.telegram.org/bots/webapps)
- `requestWriteAccess([callback])` — Bot API 6.9+; «shows a native popup requesting permission for the bot to send messages to the user… the first argument will be a boolean indicating whether the user granted this access».
- `WebAppUser.allows_write_to_pm` — «Optional. True, if the bot is allowed to send messages to the user».
- `initDataUnsafe` — «Data from this field should not be trusted»; доверять можно только `initData` после проверки на сервере.
- `isVersionAtLeast(version)` — поддерживает ли приложение пользователя версию Bot API.
Документация прямо не говорит, обновляется ли `initData` внутри одного запуска; хост поэтому всегда просит закрыть и открыть чат заново, а сервер отклоняет повтор прежних данных.
