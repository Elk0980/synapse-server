# Мобильные «Чаты» — сравнение до и после / Mobile chats

№308, локальная QA. Реальная разметка и стили кабинета, синтетические комнаты и переписка ТайСабай; сетевые запросы браузера запрещены. Реальных сообщений, данных клиентов и ключей здесь нет.

Все снимки: viewport 390×844, deviceScaleFactor 2 (JPG 780×1688, качество 80). «До» — main `333fc6e381e93204d1a612e5032ad302158ce379`, «после» — JS/CSS этого PR. Нижняя клавиатура на снимке явно помечена как эмуляция; visualViewport.height действительно подставлен в 480px. Это не проверка физического iPhone.

В браузере: лента 364.5 → 703px; шапка 116.5 → 53px; composer.bottom = 844px без клавиатуры и 480px с ней. Шрифты сообщений и ввода — прежние 16px. Высота страницы 944 → 844px, её scrollY остаётся 0 при прокрутке ленты. На компьютере 1440×1000 геометрия шапки, ленты и composer, размеры шрифтов совпали с исходными.

Автоматически проверены также новые сообщения при чтении истории, кнопка перехода вниз, загрузка ранних сообщений с сохранением места, раскрытие «i» без уменьшения ленты, рост поля до пяти строк, common/dm/hugh, возврат к меню, граница 760/761px и освобождение блокировки при выходе. 23 теста `sites/synapse/cabinet/chats.test.cjs` проверяют прежние гарантии черновиков/сессий и новые мобильные состояния; ещё 8 — контекст API и кнопку оболочки.

Воспроизведение: при доступных `playwright-core` и Chrome выполнить `node specs/308-mobile-chats/visual.cjs`. Сценарий пересоздаёт шесть JPG и `metrics.json`, закрывает все свои контексты и браузер. Для DOM-проверок нужен `jsdom`: `node --test sites/synapse/cabinet/chats.test.cjs sites/synapse/cabinet/module-registry.test.cjs sites/synapse/cabinet/shell-fab.test.cjs`. Зависимости можно предоставить через `NODE_PATH`, файлы зависимостей проекта не меняются.

Приёмка на живом кабинете и физическом iPhone (Telegram/Safari/Chrome) остаётся за Claude и Владом. Версия ресурсов — общий PR #653; этот PR не меняет cabinet.html.
