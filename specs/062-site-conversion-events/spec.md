# Достоверные события конверсии ALVI и Авокадо

Цель: измерять действия посетителя и подтверждённые новые заявки существующих
сайтов, не смешивая их с дубликатами, ошибками и загрузкой пустого прайса.

## Требования

- FR-001: callback_submit только после HTTP 201 и положительного целого id новой
  заявки; повтор и ошибка отдельны. Существующий договор API заявки сохраняется.
- FR-002: различать начало заполнения, попытку отправки и результат; невалидный
  ввод не считается отправкой, начало учитывается один раз для формы на странице.
- FR-003: этапы услуг, прайса, контактов и формы требуют активной вкладки,
  фактической видимости и короткой выдержки; пустой каталог и закрытый чужим
  модальным окном фон не считаются показанными.
- FR-004: встроенный прайс не создаёт второго счётчика; события передаются
  родителю только с ожидаемым origin, source и разрешённым идентификатором.
- FR-005: классифицировать действующую ссылку после обновления из CRM;
  сообщество/приглашение не равны личному диалогу; переход к контактам не равен их просмотру.
- FR-006: не передавать значения полей формы и свободный текст в цели; сохранять
  отказ от отслеживания, существующие режимы Вебвизора и защитить ввод полей.
- FR-007: не менять коммерческие сведения, оформление, маршруты контактов,
  права и серверный приём заявок. Не перехватывать глобальный fetch ради аналитики.
- FR-008: документировать составную цель start → attempt → submit отдельно от
  независимых просмотров. Новые события не заполняют исторические данные.

## Приёмка

SC-001: тесты различают 201/new, 200/duplicate, неверный id, сетевые и HTTP-ошибки.
SC-002: проверены реальная разметка, скрытый каталог, iframe, чужой origin/source,
динамическая замена ссылок и отсутствие полей формы в аналитике.
SC-003: браузерная проверка открытия прайса и контактов без реальной тестовой заявки.
SC-004: изменения ограничены двумя сайтами, их тестами и этой спецификацией.

Выпуск и проверка живой доставки событий — отдельная операционная приёмка.
Аналитические цифры компаний и переписка хранятся приватно, не в этой спецификации.
