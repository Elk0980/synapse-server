# План

Codex — единственный интегратор clean worktree. Существующие Claude Alvi и
Авокадо — авторы раздельных частных пакетов, финальные правки Opus 5.5 Extra.
Этот документ не является блокировкой общего сервера.

ALVI: metrika.js, callback.js, версии подключений в index.html/price.html.
Авокадо: attribution.js, callback.js, index.html/contacts.html/price.html.
Тесты обоих сайтов и новые analytics-tests. Миграций данных и изменений API нет.

1. Использовать прямой хук результата существующего callback.js, без fetch-wrapper.
2. Сохранить один счётчик; ограниченный postMessage из публичного прайса.
3. Проверять видимость и модальное перекрытие, не считать намерение просмотром.
4. Выполнить детерминированные сценарии Node/jsdom и отдельный браузерный сценарий.
5. Перед выпуском сверить владельца production; затем проверить живые версии.

Проверки выполняются без персональных клиентских данных и без отправки реальных
заявок. Внешние настройки Метрики и доставка отчёта подтверждаются отдельно.
Включение Вебвизора Авокадо не входит в этот кодовый пакет: действующая политика
его исключает; вопрос владельцу об изменении остаётся отдельным.
