# 098 · Каркас ЛК: раздел «Контент», реестр модулей, плавающий чат

Поручение Влада 04.11.2026, 23:25–23:46 (Бангкок), задача №98, часть (а) агента «А · Каркас».
Часть (б) «Настройки → Контент» (сервер и экран): specs/098-content-settings.

## Цель
В ЛК одна кнопка «Контент» с подкнопками Контент-план, Съёмка, Материалы, Постинг, Подключения, Статистика.
Рядом отдельно «Задачи», «Чаты», «Настройки» (вкладка «Контент»). Плавающая кнопка личного чата с Хью справа
внизу на всех экранах. Новые экраны пишут другие агенты как отдельные модули; каркас даёт им реестр и контекст.

## Сценарии
1. Пользователь с правом autoposting.view или content-plan.approve открывает «Контент» и видит 6 подкнопок.
2. Подкнопка, модуль которой ещё не зарегистрирован, показывает заглушку «Скоро» со ссылками на прежние экраны.
3. «Постинг» открывает прежний автопостинг (#content-factory/plan) без изменений.
4. «Статистика» до регистрации модуля показывает прежнюю «Статистику контента»; «Чаты» — прежний чат проекта.
5. На 390 px нет горизонтальной прокрутки; меню «Контент» открывается из нижней панели.
6. Модуль агента подключается одной строкой в список shellAssets/shellStyles и получает ctx (контракт).

## Требования
- FR-1 Меню: Главная → Контент (6 пунктов) → Задачи → Чаты → Настройки; соседние пункты не удаляются.
- FR-2 Реестр window.SynapseModules: register/has/get/mount; ошибка mount не роняет кабинет.
- FR-3 Заглушка «Скоро» для незарегистрированных модулей; legacy-экран, если он есть.
- FR-4 ctx по контракту contracts/module-registry.md; запросы привязаны к выбранной компании, AbortSignal при смене.
- FR-5 Плавающая кнопка чата с Хью справа внизу; скрыта на экране чатов и при открытом меню на телефоне.
- FR-6 Права видимости пунктов — существующие права people (autoposting.view, content-plan.approve, settings.view).
- FR-7 Правка cabinet.html только точечными вставками: патч применяется к живой копии без конфликтов.

## Приёмка
Тесты кабинета не хуже main; снимки 390/1440 без горизонтальной прокрутки и без ошибок страницы;
прежние экраны (автопостинг, задачи, чат проекта) показывают то же, что на main; dry-run патча на живой копии чистый.

## Ограничения
Без merge, deploy, новых прав и сообщений. Данные клиентов в репозиторий не попадают.
