# План
Root Codex — единственный писатель source ветки codex/server-revenue-analytics-20261008. Claude Opus5.5 High в двух private областях: MAX_ACCESS пишет только social-max-access.js/test, MAX_STATS — только social-max-stats.js/test; общий интерфейс фиксируется до запуска. Они читают актуальный Spec Kit packet, primary контракт и существующие модули; не выполняют команды/внешние действия. Root лично проверяет файлы и тесты, затем переносит.

social-max-access.js: существующий credential resolver provider max_analytics, отдельная таблица social_max_channels, authenticated channel/bot membership, fixed GET transport with bounded stream/lossless identifiers, revoke/revision/reference fences и stop. Native wrappers возвращают очищенный context envelope, без raw текстов/имен.
social-max-stats.js: current channel count/lifetime post views, календарные UTC bounds, guarded post pagination/boundary и explicit known ID refresh. Одинаковые IDs не суммируются. Неопределённый охват и недоступные метрики остаются partial. Root подключает persisted known-post reader/index coverage/backfill к текущей social очередь вместо нового независимого cron.

Root расширяет social-analytics-credentials/social-stats/social-adapters/social-stats-http/server и существующий кабинет. Постовые замеры получают explicit lifetime metadata и порядок observation; прежние post metrics, global context и accounts сохраняются. HTTPS mock/SQLite/actual scoped HTTP/DOM + соразмерная регрессия социальных источников и relevant CI. Перед production — свежая база/backup/rollback/одно окно; no new rights/secret creation.
