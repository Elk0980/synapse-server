# План

Один исполнитель Codex; существующая сессия Claude занята другой задачей, новый конкурирующий исполнитель не запускается. Изолированная ветка codex/besedka-sergey-20261005.

Область: sites/synapse/besedka/** и specs/091-besedka-workshop/**. Статические HTML/CSS/JS без зависимостей и внешних CDN: доступны без обращения к поставщикам 3D-библиотек. Существующий Caddy отдаёт вложенную папку сайта.

geometry.js валидирует исходные параметры и читает OBJ/STL. editor-model.js хранит детали и плоские группы, валидирует проектv2 и мигрирует v1, строит мировую геометрию и ведомость, обеспечивает операции и историю40изменений. editor.js управляет Canvas, выбором, пальцевым перемещением в плане, формами, чертежами, файлами и обучением. index.html — основной редактор; editor.html — тот же локальный вход для проверки. Старые app.js/style.css сохранены для совместимости ранее открытых страниц.

JSONv2: version=2, project=Беседка, name, notes, parts, groups. Деталь: id, name, shape(box/cylinder), dimensions/position в метрах, rotation в градусах, material, hidden, locked. Пользователь вводит размеры в миллиметрах. Группа содержит идентификаторы деталей; вращение сохраняет мировое взаимное положение. Раздельная геометрия позволяет менять элемент без перестройки всех частей. Ошибочная загрузка не меняет модель; успешную можно отменить в текущей сессии. Ограничения:400деталей,200групп,2МБ проекта,20МБ исходника,60 000вершин/граней OBJ,20 000треугольников STL. SVG содержит только числовую геометрию; пользовательский текст выводится textContent, CSV защищает формулы.

Проверки: синтаксис, исходная геометрия, редакторская геометрия/группы/повреждённые файлы; основные действия, чертёж/ведомость, два режима, показ клиенту,360px и горизонтальный телефон. Контроль области diff и CI. Для публикации только папка /opt/synapse/sites/synapse/besedka, новый согласованный доступ к synapse-core и Gitblob SHA immutable-версии. Не сливать main и не запускать общую синхронизацию. Документ не является блокировкой сервера.

Солнце: solar.js рассчитывает склонение/уравнение времени, направление солнца и границы геометрического дня по приближённым формулам NOAA. На canvas тени видимых граней проецируются на y=0, сначала объединяются непрозрачно, затем смешиваются один раз; взаимное наложение граней не затемняет тень повторно. Сцена/компас учитывают заданное направление севера. Рисуется земля и природный фон; конструктивная геометрия не меняется. Анимация останавливается при уходе со страницы/правке и сохраняет конечное время. Поворот всей конструкции использует обычную rigid-трансформацию и историю отмены.
Источник формул: https://gml.noaa.gov/grad/solcalc/solareqns.PDF
