# CF14 — безопасный контекст сохранённой статистики для следующего плана

Spec Kit1.0.0. Исполнитель Codex. Ограниченная область согласована с root01.10.2026.

## Сценарии и приёмка

1. Пользователь с правом аналитики запускает подготовку следующего месяца. В серверном снимке появляются только замечания о качестве уже сохранённой статистики прошлого календарного месяца.
2. Пользователь без owner/analytics.view получает план без такого контекста: вызывающий HTTP слой не вызывает helper. Проверка права принадлежит root и не реализуется внутри helper.
3. Данных нет либо чтение недоступно — это явное missing/unavailable, без нулевых результатов, советов об успешных темах и блокировки чернового плана.

## Требования

- FR-001. createPlanningInsights({stats}).capture(code,month) читает существующий stats.overview ровно один раз за предыдущий календарный месяц. Январь и високосный февраль обрабатываются календарно; сбор, импорт, запись, сеть и новая библиотека статистики запрещены.
- FR-002. Проекция ≤8192байт. Только schemaVersion1, companyCode, planMonth, source{kind,status,period,capturedAt}, platforms{platform,timezone,coverage,confidence,freshness,editorialRecommendations} и фиксированные limitations. Поля company/period/timezone служебные; MODEL-проекция root содержит только фиксированные рекомендации и quality labels.
- FR-003. Нет исходных значений/сумм/процентов/рангов, permalink, account/provider/reference IDs, названий частных отчётов, PII, URL, credentials, upstream labels/text/reason/error. Все редакционные тексты берутся только из фиксированного словаря helper.
- FR-004. Покрытие — качество существующих профильных измерений текущего аккаунта. Другие аккаунты, системы суток, scope и источники не объединяются. Неизвестное не считается нулём; одиночное состояние на дату не становится итогом месяца, трендом или причинным выводом.
- FR-005. Confidence только insufficient/limited/descriptive, без статистической уверенности. Freshness показывает давность сохранённого сбора, а не полноту месяца; recent — не старше7дней относительно capturedAt, stale — старше, unknown — нет допустимого времени. Порог и смысл явны в limitations.
- FR-006. Missing подтверждается как отсутствие пригодных данных и не даёт editorialRecommendations. Неблокирующая ошибка чтения даёт source.status=unavailable, пустые platforms и фиксированное limitation, без эха исходной ошибки.
- FR-007. Ни причинных выводов, ни рейтинга роликов, ни автоматического изменения плана. Early replay, права, service/worker/model projection/HTTP интеграция принадлежат root.

## Критерии успеха

Синтетические пробы подтверждают scope/month/saved-only/privacy/UNKNOWN/freshness/несопоставимость и предел размера. Helper не изменяет исходные DTO и сохранённую SQLiteБД. В старую область CF12 записи не выполняются.
