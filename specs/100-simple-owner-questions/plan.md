# План
Backend: аддитивная миграция12 добавляет проверки новых JSON-полей; прежние записи не переписывает. API читает отсутствующие поля как пустые/null, сохраняет новые поля при старых обновлениях, использует прежние scope/CAS/history/watchdog.
MCP: optional поля task_update и overview tasks_list; инструкция подготовки вопроса. Старый формат списка по умолчанию сохранён.
UI: готовность вопроса и технический фильтр, очередь подготовки, компактная панель ответа. Прежний интерфейс и обработчики остаются в закрытой расширенной карточке; черновики сохраняются.
Root владеет UI/specs/интеграцией, отдельные исполнители — backend и MCP, ревью только чтением. Публикация в отдельную ветку, без серверных действий. Откат кода сохраняет новые данные.
