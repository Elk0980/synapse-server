# План
Codex единственный автор в отдельном worktree origin/main. Использовать immutable task_coordination_history для номера смены blocker; task ID для события создания. Новый owner-only GET /internal/people/ownerDecisionEvents возвращает страницы по100 старых и новых задач и точечное актуальное событие. Существующий runtime people (60сек) читает эти события для подписанных владельцев и вызывает existing queue. Очередь перепроверяет источник до доставки. Устаревшие промежуточные blocker между тиками не отправляются. Схема БД не меняется, миграции не нужны. SW проверяет audience, company и URL; people.js обрабатывает deep link после выбора компании. Ключи, настройки доставки и сервер не менять.
