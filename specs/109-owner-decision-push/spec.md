# Push решения владельца
FR-001: Активная задача с blocker, начинающимся «ждёт Влада» (регистр/ё) вызывает push. Изменение текста блокера даёт новое событие; правка других полей — нет. Создание задачи исполнителю «Влад» тоже событие. Старые активные записи поддерживаются, завершённые и удалённые не отправляются. FR-002: Существующие owner opt-in настройки/подписки people, push-only, текст «Нужно ваше решение: №id заголовок». FR-003: Durable queue unique key, no retry uncertain; отзыв доступа/согласия блокирует отправку. FR-006 (ревью 555): при первом запуске для владельца и проекта всё уже открытое считается отправленным (базовая отметка); push только по новым событиям и изменённому blocker. Базовая отметка создаётся только после полного чтения всех страниц; новая подписка не получает старые события. FR-004: Нажатие открывает company/task карточку, URL только same-origin people.html. FR-005: Без новых VAPID; инструкция iPhone. Приёмка HTTP+unit+jsdom+Chrome390/1440, реальные push отдельно после разрешённого выпуска.
