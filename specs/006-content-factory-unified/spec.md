# Единый Контент завод

По поручению владельца объединить Материалы, Медиа-наставник и Контент завод.

## Приёмка
- FR-001: в боковом меню один пункт «Контент завод» вместо трёх.
- FR-002: внутри доступны существующие материалы/публикации и этапы/результаты внедрения; заглушка не заменяет рабочие функции.
- FR-003: старые ссылки открывают соответствующую вкладку, назад/вперёд работают; избранное старых разделов ведёт в единый раздел.
- FR-004: существующие права и разделение компаний сохранены; право content-factory.view само по себе не разрешает API материалов.
- FR-005: на мобильном экране название и навигация читаемы; переключение вкладок не уничтожает редактор материалов.

## Границы
Без переноса данных, изменения API, новых разрешений или включения публикаций. Бриф и план, анкеты, рабочее место и прочие пункты не объединяются этим поручением.
