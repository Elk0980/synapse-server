# План

Один исполнитель Codex в отдельном worktree; ранее занятый Claude не перехватывается. Область: cabinet.html, menu-preferences.js, названия в media-mentor-rollout.js, module-guide.js и тесты кабинета.

Общий заголовок и две ссылки располагаются вне контейнеров модулей. Маршруты content-factory/materials и content-factory/progress используют существующие внутренние view, рендеры и проверки доступа. Старые адреса нормализуются оболочкой без запроса к серверу. Право открытия общего раздела — объединение прежних прав; рабочие вкладки требуют прежнего autoposting.view. Старое избранное нормализуется с удалением дублей.

Миграций БД и новых зависимостей нет. Проверки: полная оболочка с mock API (переходы, права, смена компании), существующие тесты модулей, ручной просмотр. Откат — возврат файлов интерфейса. Публикация и production-проверка фиксируются отдельно от локальных тестов.
