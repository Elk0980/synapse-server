# №36 — MVP рабочего чата

Поручение: один общий внутренний чат команды проекта + Хью, команда «поставь задачу» создаёт ровно одну задачу на существующей доске. Только доступные проекты, person:<id>, ПК и 390px. Владелец реализации — Codex — Рабочий чат, ревью — Claude. Никаких merge/deploy и сообщений людям/клиентам.

FR1. История команды отделена от project_chat_*: там клиентская аудитория и Telegram. Старые переписки и файлы сохраняются.
FR2. Актуальная роль human_executor/owner и компания проверяются на каждом запросе; отправка требует tasks.self.edit и CSRF. Только назначение самому себе, без смены прав.
FR3. Команда Хью создаёт запись в CRM tasks, с ссылкой на сообщение-источник; повторы одного сообщения, конкуренция и одинаковая открытая задача не создают дублей.
FR4. Неизвестный результат сохраняет сообщение и идентификатор повтора, черновик по проекту; после перезапуска повтор безопасен.
FR5. Список проектов, лента, нижнее поле ввода и отправка работают на ПК/390px; чужой проект закрыт. Доставка уведомлений #35 остаётся в прежнем выключенном режиме.

Вне MVP: личные/веточные комнаты, голос/фото, произвольные ответы моделей, команды смены статуса и отчётов, подписки и Telegram. В этой версии Хью выполняет только явно адресованное создание задачи. Формулировки клиентских системных уведомлений не меняются.
