Личная история выбора — один localStorage-ключ на userId. Счётчики вычисляются из событий за30дней. Текущий проект приходит из штатного aria-checked; изменения DOM отслеживаются MutationObserver, порядок меняется только при необходимости. Состав компаний определяет штатная оболочка. Поздняя загрузка использует существующий createContext, ранняя — перехват attachShell. Между устройствами нужен отдельно разрешённый серверный шаг; серверного кода в этой ветке нет.
