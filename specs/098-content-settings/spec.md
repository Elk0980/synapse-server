## Цель
В «Настройках» вкладка «Контент»: кто согласует контент-план (галочки), дни недели съёмки, дедлайн съёмки,
площадки, стиль титров (шрифт, размер, цвет, заглавные). Значения читают модули Контент-план, Съёмка, Постинг.

## Требования
- FR-1 GET /content/content-settings?companyCode=X — любой пользователь с доступом к компании; без сохранения
  version 0 и значения по умолчанию.
- FR-2 PUT с {version, settings} и X-CSRF-Token — владелец или право settings.edit; version+1; чужая версия 409.
- FR-3 Строгая проверка полей: лишние поля, неизвестная площадка/шрифт/размер, неверный цвет, дни вне 1..7,
  deadlineDays вне 0..60 — 400.
- FR-4 Согласующие — только люди этой компании с content-plan.approve и владельцы; другая компания — 403/400.
- FR-5 Экран settings-content регистрируется в реестре модулей (часть а); без права записи — только просмотр.
- FR-6 Хеши паролей и данные других компаний в ответ не попадают.
