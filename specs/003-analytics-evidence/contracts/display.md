# Контракт отображения

- Старый API не меняется.
- Конверсия: текст «нет сопоставимой когорты клиентов», процент отсутствует. Для потенциала остаётся прежняя причина несопоставимости.
- Числа сводки не скрываются; предупреждение поясняет пересечения и отсутствие уникальности.
- ROMI нескольких строк рассчитывается по суммам. Нет строк / null / undefined / NaN / Infinity / отрицательные расходы / сумма расходов 0 → null → «—».
- При полном наборе: revenue 200+1800, expenses 100+900 → 100%; revenue 0, expenses 100 → -100%.
- Результат не подтверждает банковскую сверку старых сумм CRM.
