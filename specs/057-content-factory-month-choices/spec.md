# CF7: выбранные форматы и ОВП месяца

Процесс Spec Kit 1.0.0. Ограниченный серверный пакет; UI и живые API не входят.

## Цель и сценарии
Владелец до составления плана может ограничить форматы публикаций и цели ОВП. Пустой выбор сохраняет прежнее поведение: все доступные форматы и цели, с учётом совместимости площадки. Обязательных процентов ОВП нет.

## Требования
- FR-001. `month.inputs.formats` — необязательный список ключей действительного `FORMATS`: post/story/reel/carousel; `roles` — список ключей `ROLES`: reach/affection/sale. Сохранять в порядке словаря. Повторы, неизвестные значения и неверный тип отклонять с 400.
- FR-002. `[]` снимает ограничения. Старые сохранённые месяцы возвращают эти поля как пустые списки; старые снимки без полей продолжают работать. Company scope, revision и объём не меняются.
- FR-003. Задание сохраняет выбранные ограничения в снимке существующей очереди. Последующие изменения месяца не меняют ранее поставленное задание.
- FR-004. Prompt передаёт выбор и явно требует соблюдать непустые списки; validateProposals отвергает формат или цель вне выбора. Совместимость площадки остаётся обязательной.
- FR-005. YouTube Shorts с ненулевым объёмом и непустым выбором без reel создаёт `needs_input` с вопросом `target: month.formats`. Выбор не меняется, исполнитель не получает это задание.

## Приёмка
Сохранение, нормализация, сброс, ошибки 400, company/month isolation, stale revision; старый JSON месяца и старое задание; неизменность снимка; prompt и отклонение неподходящего результата; конфликт YouTube Shorts до вызова модели и нулевой объём без такого конфликта.
