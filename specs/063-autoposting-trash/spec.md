# Материалы ЛК: обратимое удаление в корзину

Процесс Spec Kit 1.0.0. Прямое поручение Влада 02.10.2026 «удали все публикации с цветами которые в ЛК», задача root PALITRA-FLOWERS-DELETE-20261002. Исполнитель — Claude, единственный автор.

## Контекст и факты
- Материалы ЛК (`#content-factory/materials`) — карточки `autoposting_posts` CRM. Root через видимый селектор подтвердил: цветочные пробные карточки Palitra — №23, 24, 25 (отклонены, без даты); всего 15, №26–37 сохраняются.
- Штатного удаления нет. `reject` меняет только согласование; `cancel` доступен для очереди, а список, календарь («Без даты») и селектор всё равно показывают отменённые карточки.
- Отклонение и отмена удалением не считаются.

## Сценарии
- US1: пользователь с правом правки материалов своей компании удаляет черновую карточку в корзину; она исчезает из списка, селектора, календаря (включая «Без даты»), очереди и напоминаний о согласовании.
- US2: удалённая карточка не может уйти на площадку: обычные действия отвечают 404, фоновая отправка её не берёт.
- US3: карточку можно восстановить из корзины в прежнем виде.
- US4: повторный импорт пакета не создаёт удалённую карточку заново.

## Требования
- FR-001: мягкое удаление — признак `deleted_at` (+ автор, имя, комментарий) у строки карточки; медиа, текст, согласования, история, доставки, расписки и связи не меняются и не удаляются.
- FR-002: `POST /autoposting/posts/:id/delete` и `/restore` — только для своей компании, право `autoposting.edit` (владелец — всегда); `GET /autoposting/trash` — право просмотра. Чужая компания — 403/404.
- FR-003: обе операции требуют текущую `revision`, увеличивают её и выполняются в одной транзакции с проверкой версии в `UPDATE`; устаревшая версия — 409 `REVISION_CONFLICT`.
- FR-004: удалять нельзя: `scheduled` (сначала снять с публикации), `publishing`, `published`; карточку с доставкой `publishing`/`published`/`needs_review` или принятым заданием сервиса (`provider_post_id`) — 409 `PUBLICATION_EXISTS`; с распиской «опубликовано вне ЛК» — 409 `PUBLICATION_RECORDED`; связанную с продолжением по площадкам, переносом/версией контент-плана или стартовым планом — 409 `POST_LINKED`.
- FR-005: удалённые исключены из `list`, `calendar` (даты, «Без даты», доставки, расписки, связи плана), `reviewReminderSummary`, `reorder`, `invalidate`, выборки и захвата фоновой отправки; `rowFor` по умолчанию их не находит.
- FR-006: импорт пакета считает удалённую карточку существующей и возвращает пропуск с причиной `deleted`.
- FR-007: журнал удалений и восстановлений — отдельная таблица `autoposting_post_trash_events`.
- FR-008: интерфейс — кнопка «Удалить в корзину» в редакторе (видна при праве правки и допустимом статусе, требует второго нажатия по той же версии, без системных окон), раздел «Корзина · N» с кнопкой «Восстановить».
- FR-009: не меняются тексты и статусы других карточек, план, даты, каналы, права, настройки, production, БД вне миграции колонок, публикации и сообщения.
