# №55 — выпуск без консоли

Цель: принятый PR выпускается последовательно серверным агентом без root-консоли,
с проверкой exact SHA, backup, health, автоматическим откатом и отчётом на доске.
Полное ТЗ — задача55. Владелец реализации Codex — Выпуск без консоли; ревью Claude.

- FR1: сначала полный приватный снимок и поимённый разбор предсуществующих372
  изменений; checkout/runtime/main согласуются без удаления данных и managed слоёв.
- FR2: исходящий worker60–120сек, один first-parent commit за раз, зелёный CI
  exact PR head + Spec Kit merge SHA и связанная с PR задача с подтверждённой приёмкой Claude.
  Свободная строка автора комментария не удостоверяет личность.
- FR3: общая managed lock, полный прежний Compose recipe, адресные immutable
  images, остановка затронутых writers, VACUUM INTO + integrity/FK.
- FR4: журнал до мутаций; health failure/unknown crash → прежние images;
  новые данные сохраняются. Необратимая миграция ждёт отдельного решения Влада.
- FR5: connected evidence/outbox на доску; неизвестная отправка сверяется чтением.
  Кнопка отката требует server-side ACL Влада/Claude, CSRF, exact SHA CAS и requestId.
- FR6: секреты/recipes/env/SQLite не в git/logs; ключи/уведомления не менять.
  Чужой выпуск478/477 и общий router/board26 не трогать.
- FR7: одна окончательная команда установки после проверки полного bootstrap на
  копии и приёмки Claude. Инертная установка кандидата не закрывает это требование.

Приёмка: два реальных PR по очереди без ручных действий, успех/ошибка и откат≤5мин,
старые/новые данные, открытые сеансы, CRM/MCP/cabinet/sites/старые URL и reload.
Все критерии production остаются непроверенными до разрешённой установки.
