# 233 — Демо-сайты «вау» для рилсов Synapse Business

Цель: показать предпринимателю сайт-историю, в котором блоки движутся при прокрутке и доводят до заявки. Рилсы «ноутбук + сайт» снимает Влад.
Раскадровки: `storyboard.md`. Сайты делаем по одному. Первый образец — авто.

## Сценарии
1. Посетитель листает историю компании: кадры сменяются по прокрутке, у каждого блока свой этап продаж.
2. Посетитель листает каталог: машина приезжает на подиум из своего пейзажа, подиум поворачивается, стрелки и свайп меняют машину.
3. Посетитель видит расчёт-пример и оставляет демо-заявку.

## Требования
- FR-1: Страница `sites/drafts/<папка>/`, `noindex`. Есть title, description и H1.
- FR-2: Все компании, цены и сроки помечены как пример. Марок, логотипов и реальных фото под вымышленным именем нет.
- FR-3: Работает на 1440 px и на телефоне 390 px без горизонтальной прокрутки. Для режима «уменьшить движение» есть упрощённый вариант.
- FR-4: Демо-форма ничего не отправляет и сообщает об этом.
- FR-5: Видео Gemini подключаются только после согласования Влада.

## Приёмка
Ошибок JS нет. Скриншоты desktop и mobile проверены. Живая страница открывается по `drafts.synapsebusiness.ru/<папка>/`.
