# Небо · экскурсия: один свайп = видео до следующего блока

Решение владельца 08.11.2026: «Один раз вниз листнул, и дальше видео идёт до следующего блока.
На следующем блоке ещё раз свайпаю вниз, и видео продолжается до третьего блока и так далее».

Сайт `nebo-draft-1.synapsebusiness.ru` — импортированная статическая сборка в site workspace
(исходников приложения в репозитории нет). Поэтому поведение добавлено отдельным файлом
`assets/tour-step.js` и одной строкой в `index.html`; собранный бандл не меняется.

## Поведение
- Вниз (колесо, тачпад, свайп, ↓ / PageDown / пробел): видео проигрывается (×1.25) до кадра
  следующей остановки, страница едет за видео, на блоке — пауза ровно на его кадре.
- Ещё свайп вниз во время проигрывания — видео едет дальше, к следующему блоку.
- Вверх — плавная прокрутка к предыдущему блоку (видео назад не играет, его перематывает сайт).
- После последнего блока шаг вниз выводит из экскурсии; ниже — обычная прокрутка.
- Пока видео играет, перемотка сайта (`currentTime`) глушится; управление возвращается сайту,
  когда его перемотка догнала кадр — без рывка назад.
- `scrollTo(..., behavior: 'instant')`, потому что на сайте `html { scroll-behavior: smooth }`.
- `prefers-reduced-motion`: без проигрывания, мгновенный переход.

## Выпуск (только после «выпускай» владельца)
На сервере, в каталоге с файлами: `python3 install.py inspect` → проверить вывод →
`python3 install.py apply` → `python3 install.py verify`. Откат: `python3 install.py rollback`.
