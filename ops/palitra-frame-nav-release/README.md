# Palitra: photo frame and editor navigation
Scoped update for the existing Palitra editor. Contains the photo-frame validator and editor code, shared navigation, and a user guide. The price data and permissions remain outside this package.

The installer only changes explicitly approved code files after verifying source and target hashes. Check ownership, run check, apply backend, activate the validator in the current content image, then apply static. The public draft price-render.js is a separate native-editor change. Installation requires an existing authorized server access path; this package provides no access.
