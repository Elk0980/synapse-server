## Что изменено

- Форма «Создать публикацию»: сначала контент (название → текст → формат → файл → дата/время → пояс), затем площадки с предпросмотром, параметры площадок и статус. Шапка и кнопки «Сохранить/Отмена» закреплены. Раскрыт один предпросмотр — последней отмеченной площадки. Дата и время не выходят за край на iPhone. На ПК — две колонки: контент слева, площадки с предпросмотром справа.
- Предпросмотр: вместо «Подсветить зоны / Вписать / Заполнить» две кнопки со значком, подпись называет действие: «Скрыть зоны ↔ Показать зоны», «На весь экран ↔ Показать целиком» (только при загруженном файле с другими пропорциями).
- Раздел «Контент»: карточки площадок, на ПК — сетка (`src/palitra-content-layout.css`, новый файл, подключить в cabinet.html).
- Параметры Onlypult по площадкам (SDK @onlypult/mcp 0.1.9, openapi.yaml): Telegram — закрепление, текст над медиа, опрос; ВКонтакте — комментарии, лента/сетка, опрос; Instagram — комментарии, первый комментарий, пробный Reels; TikTok — аудитория, комментарии, дуэты, сшивание; YouTube Shorts — доступ; MAX — закрепление; у всех — автоудаление. Необязательное свёрнуто в «Дополнительно» с подсказками. Наборы по умолчанию для компании подставляются только в новую публикацию (Палитра: TikTok «Публично для всех»).
- Сервер (`ops/crm/autoposting.js`, `ops/crm/onlypult-provider.js`, `sites/synapse/cabinet/autoposting.js`): закрытая схема новых параметров и раскладка в поля запроса Onlypult; при прямом подключении бота постановка с параметрами отклоняется `OPTIONS_NEED_ONLYPULT`.
