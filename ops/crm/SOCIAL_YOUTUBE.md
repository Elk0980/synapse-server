# Измерения YouTube

Сборщик читает YouTube Analytics и Data API. Подключение публикаций остаётся самостоятельным. Установки и подтверждённого доступа ALVI/Авокадо пока нет.

В кабинете владелец сохраняет точный канал (UC ID, официальный адрес или @имя), систему суток America/Los_Angeles и отдельно данные существующего Google-приложения: clientId, clientSecret, refreshToken. Они шифруются в namespace youtube_analytics, не возвращаются в DTO и не журналируются. Допускаются только youtube.readonly и yt-analytics.readonly. Проверка использует канал из сохранённого аккаунта, не из тела HTTP-запроса; @имя сначала разрешается через forHandle, затем отдельный mine=true должен подтвердить тот же UC ID. Смена доступа, аккаунта либо окончательный отказ снимают подтверждение соответствующей ревизии.

Маршруты /social-stats/youtube/access (GET/PUT/DELETE) и /social-stats/youtube/verify (POST с пустым объектом) доступны только владельцу своей компании под существующими правами и CSRF. Поля PUT: revision, credential (JSON-строка трёх полей). Пустая credential сохраняет прежний доступ, явный DELETE убирает его. Старые измерения не удаляются.

Плановый и ручной сбор идут через один движок SQLite. Даже при выбранном Onlypult YouTube читается своим API и сохраняет происхождение direct. Данные за дату относятся к Pacific с DST; другой выбранный пояс блокирует сбор до исправления владельцем, старые точки не переименовываются. Вчера вычисляется по календарю, без вычитания24ч из момента перехода DST.

views и engaged_views сохраняются отдельно; estimatedMinutesWatched переводится в watch_time_seconds. Текущие подписчики — lifetime в день наблюдения; пропуск суточной строки неизвестен, не0. Полный закрытый день не ставится в очередь из-за постоянной оговорки округления. Поздний отчёт повторяется с сохраняемой задержкой. Отзыв доступа и временный лимит различаются. Проверяется принадлежность ответа и ревизия до/после сети.

Адреса OAuth/Google API и допустимые параметры фиксированы; перенаправления не выполняются. Тело читается ограниченным потоком, каждый запрос имеет срок и отмену; у сбора за дату общий срок30с. При остановке сначала прерываются YouTube запросы, затем ожидаются активные ручные и плановые задания до закрытия SQLite. Запоздавшие числа после остановки не сохраняются. История, очередь и старые таблицы при откате сохраняются; перед рабочей установкой обязательны свежая точная база, backup/rollback и подтверждённое окно одного писателя.

Локально:191 backend-тест (включая существующие VK/TG/Onlypult, ACL, изоляцию, ревизии, очередь/reopen и новые YouTube module/HTTP/SQL/lifecycle/DST),21 DOM-тест — pass, fail0. Google заменён искусственными Response: это не подтверждение рабочих каналов, Studio, установки, рабочего перезапуска или второго планового цикла. Полный goal всехисточников/цепочки/экономики ещё не достигнут.

Контракты: [channel reports](https://developers.google.com/youtube/analytics/channel_reports), [metrics](https://developers.google.com/youtube/analytics/metrics), [channels.list](https://developers.google.com/youtube/v3/docs/channels/list), [OAuth offline](https://developers.google.com/identity/protocols/oauth2/web-server#offline). Spec: specs/092-youtube-regular-analytics.
