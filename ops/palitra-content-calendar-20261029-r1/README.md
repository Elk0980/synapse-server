# Palitra: лента дней и календарь Контента

Точечный первый этап specs/049-palitra-content-calendar: семидневная лента, выбор даты, горизонтальный свайп и полный календарь с месяцами. Исходная оболочка прочитана по актуальным публичным URL 29.10.2026. Только 3 статических файла; API, права, данные, материалы и публикации не меняются. Новый календарь находится в существующем модуле, поэтому старый HTML с прежними query тоже получает функцию.

Пакет не содержит фото пользователя, бизнес-данных или секретов. Следующий этап формы публикации не входит в этот установщик и не считается выполненным.

## Проверки

`node --test calendar.test.cjs` с установленным jsdom; `python -m unittest discover -s . -p test_install.py`; `node --check payload/sites/synapse/cabinet/palitra-orders/palitra-content-tasks-ui.js`.

Установщик требует Linux/root и принадлежащий текущему родительскому shell flock `/opt/synapse/.palitra-app-release.lock`. `stage <immutable commit> <manifest SHA256>`; `prepare` создаёт fresh BASE и точные резервные копии; `apply` разрешает одну попытку с CAS, fsync и readback; отдельный `inspect` повторяет проверки. Полный текущий прайс, другие статические файлы, managed policy, Caddy, Compose и эффективные образы/конфигурации всех пяти контейнеров сохраняются и сравниваются с фактическим prepare. Никаких docker lifecycle, БД или Git reset.

Не использовать старые apply/backup/BASE. Если изменилась основа или исход неизвестен — сначала читать фактическое состояние. Срок prepare 15 минут. Блокировка старого sync остаётся включена. После проверки own lease освобождается и проверяется свежим lslocks.
