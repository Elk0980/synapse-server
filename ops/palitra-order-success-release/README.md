# Подтверждение принятой заявки Palitra

Один общий доступный диалог для корзины и формы подбора. Открывается только после штатного ответа 201 или идемпотентного 200 с `ok:true` и действительным `orderId`. Кнопка «Написать менеджеру» использует только проверенную одноразовую ссылку сервера; при её отсутствии выбранный контакт остаётся основным способом связи.

Отправка, CSRF, тайм-аут, идентификатор повтора и вычитание отправленного снимка корзины сохранены. Закрытие окна не отправляет запросов; Tab удерживается внутри окна, Escape возвращает фокус. Изменение хранится штатной историей версии сайта, данные прайса и права не меняет.

Проверены 19 проверок фактических экспортов, обе формы, 11 сценариев ответа, узкий экран, клавиатура и запасной режим. Новых рабочих заявок для этой проверки не создавали.
