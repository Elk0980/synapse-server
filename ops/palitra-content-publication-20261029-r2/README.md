# Palitra: публикация внутри приложения

Spec: specs/049-palitra-content-calendar

Кнопка создания открывает встроенную форму: название, площадки с раскрываемыми предпросмотрами, формат, фото или видео, дата/время и часовой пояс компании, текст, сохранение черновика. Цели ОВП нет; переход в другой кабинет не нужен. Общая существующая модель материалов автоматически используется и Synapse Business. Сохранение не запускает внешнюю отправку.

Предпросмотр показывает файл целиком по умолчанию, контуры интерфейса служат ориентиром. Геометрия внешних приложений зависит от устройства и их версии. Нет новых подключений, прав или фоновых публикаций. При неизвестном исходе повторный POST блокируется, выполняется только чтение по уникальному маркеру; независимое чтение подтверждает успешный черновик. Данные и файлы формы сохраняются при ошибке.

Изолированные компоненты подготовили Codex и Claude Opus5.5; основной Codex выполнил интеграцию и независимые проверки. Личные снимки и пользовательские примеры находятся только в приватном отчёте.

## Установка

Только9точных static файлов под новой собственной lease, freshBASE, пять резервных копий, CAS. Четыре новых asset устанавливаются до зависимостей, HTML последним. Stage принимает immutablecommit и manifest SHA, helper pin обязателен. Prepare действует15минут. Один apply, отдельный inspect. Runtime/БД/настройки/права/прайс/контейнеры/Caddy/Compose не меняются. Старый sync остаётся выключен. Отдельный rollback допускает только доказанные собственные before/after состояния. Старые установщики не повторять.

Проверки: node --test *.test.cjs с jsdom; python -m unittest test_install.py. Browser и фактическая установка фиксируются отдельно в spec/evidence и приватном отчёте, тесты не заменяют эти состояния.
