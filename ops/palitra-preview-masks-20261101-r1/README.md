# Палитра — маски предпросмотра

Spec: specs/049-palitra-content-calendar (FR-11).

Два существующих статических файла: общий preview JS и CSS. Шесть площадок получают различимые карточки/вертикальные маски с декоративными символами. Загруженные размеры фото/видео уточняют пропорции, сохраняя проигрыватель при вводе текста. Высота вертикального кадра учитывает короткое окно. Старые материалы и новая форма используют прежний create/update/dispose API.

Маски — ориентир, не точная копия всех версий приложений. Проценты зон не объявляются официальными. TikTok прямо указывает зависимость зоны от размеров, подписи и формата: https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads?lang=en-GB . Для Shorts символ сердца согласуется с объявленным обновлением YouTube25.06.2026: https://blog.youtube/news-and-events/youtube-shorts-experience-updates-features/ . Справочная форма Telegram: https://core.telegram.org/widgets/post . Внешние виджеты/скрипты не встраиваются.

`review.html` — изолированная визуальная проверка с вымышленными изображениями. Она не входит в production payload. Проверки: 24 DOM-теста, матрица6×4форматов, фактическая CSS-ширина320/390 без горизонтального переполнения; отдельные восемь offline проверок процедуры выпуска. Ошибки инструментов и реальные screenshots перечисляются в приватной квитанции, а не выдаются за PASS.

Только новый namespace, один stage/prepare/apply и отдельный inspect. CSS ставится перед совместимым JS. Свежая own ancestor lease, 900s, backup, per-file CAS, прочая статика, пять контейнеров и прайс83 остаются под проверкой. Управляемый сайт338/вся физическая история338 версий проверяются через неизменные readonly primitives SHA-c90726 и ранее принятый независимый readback. Прошлые permits не возобновляются. SQL/контейнеры/общие сервисы/аккаунты/настройки/отправка/расписания не изменяются.
