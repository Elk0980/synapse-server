# Палитра: необязательные фамилия и адрес

Проверенный код, ещё не установка. Spec092. Ровно две правки подписи/required в каждом из двух файлов. Маска+7, подстановка текущего аккаунта, авторизация, согласия и обработчики сохранены. Пустая строка остаётся явной очисткой; отсутствие поля сохраняет прежнее значение. Адрес выбранной доставки в оформлении остаётся отдельным требованием.

Перед сохранением обязательна независимая приёмка обоих scoped runtime SHA из manifest. Установка только штатным site-files CAS в новую версию, с собственной свежей lease, резервной копией и проверкой всей текущей основы. Storefront сохраняется первым, register вторым, ровно один Save каждого. Если основа изменилась — остановка и новый анализ, без восстановления старого полного сайта. Старые Save331/332 не повторяются.

Root повторил7 проверок реального DOM и SQLite с scoped backend: регистрация без двух полей, профиль существующего клиента, намеренная очистка, отсутствие поля, сохранённые security headers и отрицательный сценарий прежнего сервера. Полная обратная подстановка возвращает исходные байты. Кандидаты LF; нормализация textarea не меняет SHA. Это не телефонный OTP-вход и не готовое восстановление пароля. Личные данные и приватные доказательства в пакет не включены.

Основа регистрации взята из текущего managed редактора00db, а не производной публичной страницы03def. Существующий meta noindex/nofollow сохранён побайтово.
