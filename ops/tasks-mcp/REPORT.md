## SQL-совместимость: результаты отдельного исправления

Актуальное поручение: отдельный PR на `codex/tasks-mcp-sqlite-compat-20261103` от `c057967`; до ответа Claude «принято» не сливать и не выкатывать. PR #472 уже слит и выпущен с версией схемы 8. Миграция 9 выполнена только на испытательных базах и изолированной копии; в боевую БД не применялась. Откат боевого не выполнялся.

Причина: индекс `agents_name_key_uidx` и reviewer-триггеры версии 8 содержали 33 вложенных `replace`. Node SQLite открывал их, а Python SQLite 3.45.1 отвечала `malformed database schema (agents_name_key_uidx) - parser stack overflow`. Это несовместимость парсера; работоспособность Node и целостность данных проверялись отдельно.

Исправление: короткий индекс и CTE-триггеры с той же нормализацией; `migrate(9)` заменяет три объекта, добавляет два и сохраняет все остальные объекты/строки. Перед DDL проверяются неожиданные канонические дубли. Свежая миграция 8 также создаёт переносимые объекты.

## Ресурсы и существующие точки входа

Проверен официальный Caddy 2.11.7: весь `Caddyfile` прошёл `validate`. На отдельном loopback HTTP-стенде использованы реальные адаптированные маршруты этого файла: `board` отдаёт `308` в `cabinet.html#tasks`, MCP без секрета — `401`, существующий прокси кабинета — `200`. Запрос `tasks.js?v=old-open-session` вернул текущие байты файла и `Cache-Control: no-cache, must-revalidate`.

Это описание первоначальной локальной проверки маршрутов. При последующем выпуске TLS/DNS и Docker-образы проверены отдельно, как указано в актуальном evidence.md. Docker на этом компьютере отсутствует; Compose разобран YAML-парсером: добавлен один сервис без опубликованных портов, CRM осталась внутренней, каталог документов монтируется только для чтения, а `create_host_path: true` разрешает Compose создать пустую папку. Штатный CI проверяет `docker compose config --quiet`. `synapse-sync` использует `git reset --hard` без `git clean` или `rsync --delete`, поэтому игнорируемые приватные каталоги этим скриптом не удаляются.

Общий прежний `ops/crm/smoke-test.js` остановился на строке 915: ожидал `200` при повторе старого `sourceRef` без исходных компании и источника, получил `201`. **Та же ошибка воспроизведена на чистом исходном `f23fc96`**, без изменений PR. Проверки до этого места прошли, дальнейшие шаги этого smoke-теста не выполнены. Нельзя считать весь общий smoke-тест прошедшим; обработчик и тест вне объёма PR не менялись.
