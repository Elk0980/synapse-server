- `reviewer ≠ executor` проверяется и в новом API, и при изменении старым CRUD. Изменение старой задачи повышает общую ревизию; устаревшая открытая форма получает `409`. Системное событие старого CRUD помечается `updated_by=0`, без ложной атрибуции владельцу.
- MCP использует официальный SDK и Streamable HTTP. Авторизация — разрешённый ТЗ временный секретный путь; OAuth 2.1 ещё не реализован. Новые настройки в `.env.example` пустые. `SECRET_VALUE=REDACTED`.
- Кабинет показывает исполнителя и проверяющего, стадии, источник, подзадачи и прогресс, ссылки и фото/видео, комментарии, план дня Bangkok и агентов. История подгружается страницами, черновики сохраняются при ошибке и перезагрузке. Межпроектные ссылки сначала выбирают компанию.
- Агент со `state=work` и просроченным обновлением активной задачи получает отметку «нет отчёта». Повторный `session_start` возобновляет открытую сессию; старый `session_end` не переводит новую сессию в `idle`.
- Добавлены один сервис Compose и один заменённый блок Caddy: MCP на `tasks.synapsebusiness.ru`, старый `board.synapsebusiness.ru` перенаправляется в существующий кабинет.
- Подготовлен ручной идемпотентный импорт seed: начальные статус и ссылки записываются атомарно, идеи получают `inbox`; повтор не сбрасывает последующие правки.

Остальные обработчики, taskDispatch, чат-сервис, Хью-runtime, лиды, контакты и сделки не изменены. Тестовые обращения к CRM выполнялись только с временными данными локального стенда.
