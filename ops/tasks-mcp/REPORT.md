## Ресурсы и существующие точки входа

Проверен официальный Caddy 2.11.7: весь `Caddyfile` прошёл `validate`. На отдельном loopback HTTP-стенде использованы реальные адаптированные маршруты этого файла: `board` отдаёт `308` в `cabinet.html#tasks`, MCP без секрета — `401`, существующий прокси кабинета — `200`. Запрос `tasks.js?v=old-open-session` вернул текущие байты файла и `Cache-Control: no-cache, must-revalidate`.

Это локальная проверка маршрутов. Боевые TLS/DNS и Docker-образ не проверялись. Docker на этом компьютере отсутствует; Compose разобран YAML-парсером: добавлен один сервис без опубликованных портов, CRM осталась внутренней, каталог документов монтируется только для чтения, а `create_host_path: true` разрешает Compose создать пустую папку. Штатный CI проверяет `docker compose config --quiet`. `synapse-sync` использует `git reset --hard` без `git clean` или `rsync --delete`, поэтому игнорируемые приватные каталоги этим скриптом не удаляются.

Общий прежний `ops/crm/smoke-test.js` остановился на строке 915: ожидал `200` при повторе старого `sourceRef` без исходных компании и источника, получил `201`. **Та же ошибка воспроизведена на чистом исходном `f23fc96`**, без изменений PR. Проверки до этого места прошли, дальнейшие шаги этого smoke-теста не выполнены. Нельзя считать весь общий smoke-тест прошедшим; обработчик и тест вне объёма PR не менялись.
