# Только чтение причины отказа

Отдельный диагностический сценарий проверяет закрытые версии кода и свежую собственную блокировку, затем читает состояние по четырём фазам. Не выполняет повтор старой предварительной проверки, сборку, установку, перезапуск или изменение данных.

Вывод ограничен классами ошибок, известными безопасными кодами и хешами. Строки исключений, окружение, содержимое записей и полные снимки не выводятся. Прежние журналы и замороженный пакет сохраняются. Это не разрешение установки.
