# Дневной cache отчётов — только доставка кода

Один проверенный backend-файл; прежнее рабочее место Палитры сохраняется. В каталоге нет допуска на установку и клиентских данных.

Stage helper принимает только неизменяемый commit и свежую точную собственную lease. Все файлы закрытого архива проверяются до размещения кода в новом private-каталоге; сборки, перезапуска, изменения БД или публикации отчёта здесь нет. UNKNOWN не повторять.

Шаблон допуска отключён. До включения одного допуска нужны отдельный свежий native preflight и конкретный закреплённый Root runtime review. Шаблон никогда не выполняет apply. Откат кода обязан сохранять новые живые данные; старые копии БД поверх них не восстанавливать.
