# Palitra: заполнение обложек и самостоятельная настройка кадра

Пропорциональное заполнение одинаковых карточек товаров и категорий без пустых полос. В едином редакторе можно увеличить и сдвинуть кадр загруженной обложки; исходные файлы сохраняются. Сохранённые кадры V1 совместимы, цены и расчёты не меняются.

Закрытый набор кода: 2 runtime-модуля и 5 статических файлов; отдельно 37 файлов управляемого сайта (35 HTML и 2 общих ресурса). Родитель — установленный image023ff079, CRM неизменна. Точный пакет прошёл личное локальное ревью Root: геометрия 440 фото, 43 проверки сохранения, старый редактор, все 35 страниц desktop/390. Это не установка и не физическая приёмка телефонов.

Перед установкой обязательны точный объединённый REVIEW_READY, Root compatibility review, свежая защищённая доска/очередь, своя native lease, актуальная BASE и read-only backup. Один native apply, независимое чтение; 37 управляемых файлов сохраняются штатным редактором с CAS и побайтовым readback. При неизвестном исходе сначала читать фактическое состояние. Старые установщики не повторять.

Только публичный код. Приватный прайс, экспорты доски, фотографии-файлы, клиентские данные, токены и базы в пакет не входят. Никаких изменений auth/ролей/подписок/CRM, реальных тестовых заявок, сообщений, согласий или Push.
