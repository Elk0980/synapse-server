# Palitra: календарная дата публикации

Spec: specs/049-palitra-content-calendar

Реальная проверка сохранения выявила, что dayKey существующего сервера — недельный слот D1…D7, а не календарная дата. Форма теперь не передаёт dayKey; выбранная дата и часовой пояс сохраняются через scheduledAt/timezone. Транспорт принимает штатные недельные значения только при явном наличии; при перечитывании корректно учитывает пустое значение сервера. Проверка контракта использует реальную функцию dayKey из ops/crm/autoposting.js.
