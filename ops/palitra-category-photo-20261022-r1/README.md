# Отдельные обложки категорий Palitra

Код подготовлен и прошёл30проверок и браузерный локальный сценарий загрузки, замены, сохранения, повторного открытия и сброса. Это не подтверждение установки.

Нативный пакет ограничен8файлами (3runtime/5static) и точным установленным родителем f5c811da…b37a1. Прайс, бизнесданные, schema, роли, подписки, server.js иCRM не изменяются. Helper наследует прежние полные guards без удаления; отличия только namespace, точный parent pin и подписи задачи.

`managed-index.html` публикуется отдельно штатным редактором после свежей сверки версии292. Вне единственного скрипта категорий весь HTML точен прежнему: пять новых стандартных обложек, формы, стили, прочие скрипты и контент сохранены.

До runtime обязательны свежие приоритеты/паузы, проверка очереди/собственная lease/BASE/backup, один apply и независимое повторное чтение. При отказе или неизвестном исходе только чтение факта, без повторения. Старые установщики не запускать. Физические телефоны не проверены. Приватных экспортов, прайса, снимков БД и пользовательских фотографий здесь нет.
