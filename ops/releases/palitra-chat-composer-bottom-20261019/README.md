# Palitra: нижняя строка чата

Код обновления старой страницы чата и общего интерфейса приложения. Скрепка, поле и отправка остаются внизу; статусы и предложение обновления — выше. Приём, повтор отправки и данные не меняются.

Закрытый пакет содержит только два установщика, манифест и пять UI-файлов. Подготовка проверяет точные байты и только размещает код; применение требует отдельного свежего решения Root и полной проверки основы31. Автоматического повтора и отката нет.
