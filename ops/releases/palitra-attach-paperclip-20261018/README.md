# Компактная скрепка в существующих чатах Palitra

Только shell.js и shell.css. Прежний контроллер выбора и отправки файлов сохранён. Закрытый пакет из5 кодовых файлов; prepare только проверяет и размещает код, без применения. Установка требует отдельной свежей исключительной блокировки Root, точной основы26, собственной квитанции и проверки результата. Клиентские данные и секреты в этот transport не включены.
