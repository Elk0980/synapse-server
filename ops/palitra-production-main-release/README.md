# Palitra: общий магазин на основном домене и черновике

Пять content-файлов поверх проверенного `palitra-production-content:20261013`. Явный `PALITRA_MAIN_ORIGIN=https://palitra-love.ru` включает основной домен; канонический черновик продолжает работать. Оба адреса используют существующие workspace, SQLite, native `siteOrders`, outbox и центральный прайс. CRM и client-bot-orders остаются выключенными.

`payload/site` содержит 44 текущих файла, из них 40 изменены: удалены тестовый перехват запроса и блокировка отправки, плашка черновика; границы каталога согласованы с 5000/8000. Товарные цены и документы прайса не входят в пакет. `manifest.json` задаёт точные BASE/CANDIDATE SHA и ожидаемую ревизию 248. Публикация только через штатное сохранение workspace с CAS, историей и readback.

Root проверил сборщик, обратное восстановление байтов и семь Main/Draft тестов; независимая проверка блокирующих замечаний не нашла. Это не доказательство живой доставки ботом. После установки Root проверяет оба адреса, оформление, актуальный прайс и фото; привязка менеджера выполняется штатным человеческим путём.

`caddy-main.py` меняет только основной Palitra, старую точку входа приложения, маршрут защищённой таблицы и удаляет старый тестовый prefix. Stage требует свежий SHA, сохраняет BASE, проверяет обратный diff и штатный Caddy validate. Apply/revert используют CAS и readback; reload failure возвращает прежнюю конфигурацию. Приватная таблица и её seed в Git не включены.

При откате кода сохранять текущую базу, прайс и пользовательские проверки. Root — единственный installer. Пакет сам не отправляет уведомления и не выдаёт права.

Две ранее принятые подмены общего ракурса теперь независимы от режима отправки: SHOWCASE_PHOTO_OVERRIDES. Условие sourcePhoto и обход для редактора сохранены, цены не меняются.
