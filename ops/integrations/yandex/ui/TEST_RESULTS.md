# Проверка UI — 28.10.2026

Команда:

```powershell
node --test ops/integrations/yandex/ui/ui.test.mjs ops/integrations/yandex/ui/bridge.test.mjs
```

**26 тестов PASS**, Node v24.18.1. Сетевых вызовов нет; transport в bridge полностью синтетический.

Проверено:

- Подмена companyId, смешанный ответ с чужими объектами, посторонняя привязка и поздний ответ предыдущей компании не раскрывают данные.
- Строковый 64-битный ID не теряет точность; уже округлённый Number отвергается.
- Пользовательский/серверный текст экранируется в HTML, атрибутах и textarea; произвольная ошибка транспорта не выводится.
- Неизвестный исход и ложная успешная квитанция без совпавшего readback не становятся успехом и блокируют повтор.
- Поздний отказ A после переключения B сохраняет неизвестный результат A, не показывая данные/ошибку A в B; возвращение к A до завершения записи не разрешает параллельный повтор.
- Старое предложение с тем же текстом не подтверждает новый объект: сравниваются созданные ID/digest/срок.
- Неизменённые факты с разными источниками и точными исходными датами сохраняются без замены provenance. Частичное редактирование меняет источник/дату только изменённого факта.
- Серверный `reconciled_locked` сохраняет блокировку; неизвестный enum не получает успешную подпись.
- Существующие варианты заголовков/текстов сохраняются; неподдерживаемое сокращение вариантов отвергается до отправки.
- Новая компания не получает чужие цели, бюджет или факты. CPL/CAC и платящие клиенты без соответствующих доказательств остаются неизвестными.
- Реальный соседний server-класс на локальных fixtures: onboarding пустой компании, профиль с источником и датой, сохранение старых фактов, импорт черновика, предложение агента, согласование другим пользователем, постановка задания и чтение того же задания после создания нового экземпляра сервиса.
- Постановка задания не изменяет рекламный объект. Тестовый transport разрешает только `get`; исполнение `update` в bridge не запускается.
- Две demo-компании изолированы. Демонстрация не предоставляет OAuth, внешний executor, launch или payment; перезагрузка сбрасывает только учебное состояние.

Ограничения приёмки: HTML-представление проверено контрактным тестом с минимальным DOM-контейнером, не браузером. Реальные desktop/mobile, screen reader, production-auth/CSRF, HTTP-host, закрытие настоящего браузера и OAuth не проверены. CSS и доступная разметка подготовлены, визуальная приёмка остаётся этапом монтажа на свежий кабинет.
