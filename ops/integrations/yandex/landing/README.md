## Источник и сохранённый контракт

Использован только свежий публичный снимок Root от 28.10.2026:
свежий публичный HTTPS-снимок, переданный координатором.
Полные SHA/размеры — `BASE_MANIFEST.json`. `index.html` SHA `a7ff72162e9568d0fd6330a4b32bd1c6bbe20f071e11785c6d2f4eb3e4721b07`, `price.html` SHA `f924aa191fefd377b0663fe7aa4423f192bca2143b7e32378e1dfa23d1312ea9`. Устаревшая репозиторная или 23Oct копия не использовалась.

Цена, длительность, состав и ограничение первого визита читаются **только GET `/api/price` → `first-visit` → `first-1`**. В HTML/JS нет запасной цены или копии состава. SHA проверенного объекта — контроль неожиданной смены предложения, а не второй прайс. При недоступности, смене цены/состава, дублирующихся ID или небезопасной ссылке предложение скрывается: старые цифры не остаются. Доступны общий прайс и запрос обратного звонка. Пересмотренный оффер требует новой сверки и pin, без автоматического принятия новых обещаний.

Верхняя основная CTA ведёт к своей `#callback`. Отдельная кнопка онлайн-записи появляется только после проверки оффера и ведёт в существующее общее меню YCLIENTS; предвыбор процедуры не обещан. Общий прайс — `/price.html#first-1`, контакты/FAQ остаются на основном сайте.

`section#callback` вставлен **побайтно из свежего index.html**, включая самостоятельное согласие без галочки, обязательные поля, необязательный комментарий, сообщение результата и запасной телефон. Отправку выполняет существующий `/callback.js?v=20261001-goals`; атрибуцию — существующий `/attribution.js?v=20261001-goals`. Они не изменялись и в выпуск не дублируются. `data-company-code="avokado"` сохранён. Другого submit-контракта или собственного POST нет. Относительные `consent.html`/`privacy.html` рассчитаны на размещение обеих страниц **в корне того же сайта**.

Сохранённая граница: общий attribution переносит 5 UTM и yclid в ссылках; существующий callback POST передаёт 5 UTM, **но не yclid/ClientID**. Эта работа не добавляет их в CRM и не доказывает связь с оплатой. YCLIENTS-переход не подменяет `callback_submit`: эта цель остаётся только у подтверждённой сервером новой заявки.

## Локальные проверки без реальных заявок и метрики

Из этой папки:

```powershell
node --test tests/landing.test.cjs
python -B -m unittest discover -s tests -p "test_fixture.py"
```

Тесты проверяют API/GET, pin и отказ при смене оффера, XSS/URL, exact form/runtime SHA, одинаковый источник обеих страниц, отсутствие предзаполненного согласия, UTM/yclid в существующем attribution и старый callback-контракт. Это не визуальная приёмка.

Fixture **не запускался исполнителем**. Root может поднять один нужный локальный процесс:

```powershell
python -B fixture_server.py --port 61334
```

Открыть `http://127.0.0.1:61334/`. Bind жёстко `127.0.0.1`, без прокси/доступа к серверу. Используются скопированные публичные bytes. Fixture-only guard вставляется сервером до runtime: отправка формы и внешняя навигация запрещены, реальный загрузчик Метрики не запускается; CSP блокирует внешние script/connect и любые form actions. Любые POST/PUT/PATCH/DELETE получают 405 без обработки тела и без пересылки. Производственные файлы QA-флагов не содержат.

Отдельные режимы: `--price-case unavailable` и `--price-case unexpected`. Для смены режима Root останавливает свой процесс и запускает нужный; существующие пользовательские процессы не завершать.

Browser QA Root: 320/390 px и desktop, длинный заголовок, форма/комментарий/согласие, переход `#callback`, загрузка и обе ошибки прайса; проверка отсутствия перекрытия и горизонтального скролла. Вёрстка поточная: нет fixed/sticky CTA, форма не перекрывает клавиатуру концептуально. Физическую клавиатуру и телефон этим не считать проверенными. В fixture запрещена настоящая E2E-отправка; штатная отправка требует отдельного разрешения и проверяется после разрешённого выпуска.

## Безопасный следующий шаг и откат

Root сначала принимает локальный кандидат и сверяет реальный способ выдачи `avokado38.ru`, текущие четыре целевых пути, неизменные зависимости, `/api/price`, свежие BASE/квитанцию/занятость ресурса. Публичный снимок не доказывает server HEAD, активную lease или право публикации. Затем — отдельный exact code-only REVIEW_READY/совместимость и только разрешённый guarded release с BASE/CAS/backup. Не применять старый восстановительный installer. Формы, цены, CRM, согласия, auth, права и бизнес-БД этим кандидатом не меняются.

Откат отдельного будущего выпуска — вернуть ровно эти четыре пути к captured-before байтам либо удалить только доказанно новые файлы по квитанции. Старые сайты, заявки, JSON прайса, общие callback/attribution и БД не откатывать. URL объявлений до фактической live-проверки Root не менять; расходы и модерация запрещены.
