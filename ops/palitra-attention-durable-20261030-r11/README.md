# Palitra R11 — приватный пакет кода, не разрешение на нативную установку

Пакет `palitra-attention-durable-20261030-r11` подготовлен по прямому выбору Root:
вместо модуля R1 используется принятый модуль PRIVATE_MANAGED_FAST_R2 с SHA256
`9d00a086c983a0a7435cf6a6a2f726b570bc787bf52f56fc294ae03684aa640b`.
Байты, включая CRCRLF, копируются без нормализации. Первые 6429 байт — полный
оригинальный модуль с SHA `69690754e6efb394e3fede769257dc39df7fd1fe221d018c5cd7f77e346aa2cd`.

Основание: 34 файла замороженного R10. Их исходные SHA проверены по registry
`904181873460d20682950472889fbeb802718dcf111353282876be2aa66b7eb7`.
R10, черновик R11 на R1, R1 и R2 не переписаны. SOURCE_LINEAGE.json и
R10_TO_R11.diff фиксируют ограниченный переход. В install.py только NAME и два
значения REVIEWED_DATA_PINS (managed_history.py и scope-review.json).
Обратные три замены восстанавливают полные байты R10 helper. Остальной AST,
функции, вызовы проверок, TTL, границы данных и фаз не изменены.

В пакете остаются те же шесть payload: четыре файла контентного контейнера и два
файла кабинета. Все их before/after SHA и байты совпадают с R10. Родитель контента
фиксирован на R7 `sha256:e22ca4d3892a01454d749fbef49c10c2a1a93f0a863d977914f32ae21455a343`.
Пять ожидаемых image identities, управляемая версия334/141файл, история334 и прайс83
не меняются. CAB файлы сохраняют 0600/root/root/nlink1. CRM, другие компании,
записи, согласия, аутентификация, очереди, флаги и секреты не входят в изменения.

manifest.json имеет обязательный технический статус ROOT_REVIEWED_CODE_ONLY.
Этот статус не означает окончательную приёмку Root, актуальное разрешение или
прошедший нативный guard. Он не содержит свежую lease/permit и не отменяет ни одну
существующую проверку. Нативные receipt, приватные Env/baseJSON и пользовательские
данные в пакет не передаются. Оценка времени окна не гарантирует его достаточность:
прежние fail-closed условия действуют без ослабления.

Локальные проверки из этой папки:

    python verify_source.py
    python -m unittest test_runtime_host test_managed_history test_host_static test_r9_lineage test_host_metadata -q

Имя test_r9_lineage.py историческое: теперь единственный тест этого модуля
проверяет R10→R11, неизменность AST, SHA и точные байты R2/FULL, все data pins,
совместимость manifest с неизменной validate_manifest и шесть прежних payload.
Остальные четыре модуля тестов байтово равны R10. Fixtures используют только
синтетические временные файлы/SQLite; напечатанные ими имена стадий и JSON о
recreation/readback — синтетические события, не результат действий на сервере.

FREEZE.json и VERIFICATION.json фиксируют только реально завершённые локальные
проверки. SHA256.json регистрирует весь приватный пакет, кроме себя. Root отдельно
читает полный diff, проводит независимый повтор, выбирает окончательный выпуск,
проверяет свежие исходники/компании/lease/base/окно, и только сам выполняет
разрешённые нативные стадии. R9/R10 и черновик не воспроизводить. Этот агент не
выполнял Git, браузер, сеть, API, нативные команды, выпуск либо реальные DB writes.
