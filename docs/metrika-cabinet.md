# Метрика в кабинете

Отчёт читается сервером из официального API при открытии сквозной аналитики.
Показатели: визиты, уникальные посетители за весь выбранный период, просмотры.
Это не фоновый импорт и не замена атрибуции заявок CRM. Отчёт показывается отдельно,
без сложения с событиями сайта, без суммирования ежедневных уникальных посетителей.
Фильтр площадок CRM к этому блоку не применяется. Период — до года, даты трактует
Метрика в часовом поясе счётчика. Кеш успешных ответов — 5 минут, только в памяти.

## Подключение

На сервере в приватной `.env` CRM задать для каждой компании:

```
METRIKA_COUNTER_ALVI=112777602
METRIKA_TOKEN_ALVI=<OAuth с metrika:read>
METRIKA_COUNTER_AVOKADO=112772817
METRIKA_TOKEN_AVOKADO=<OAuth с metrika:read>
```

Это действующие счётчики, проверенные 24.09.2026; новые номера из переписки не
подставлять без сверки доступа и установки на сайте. Секреты не коммитить,
не отправлять в чат, не вставлять в адрес страницы. Токен принадлежит Яндекс-аккаунту
с доступом к соответствующему счётчику. После изменения окружения пересоздать CRM
штатным способом развёртывания. `env_file` CRM уже читает приватную `.env`.

OAuth: https://yandex.ru/dev/metrika/ru/intro/quick-start
API отчётов: https://yandex.ru/dev/metrika/ru/stat/

`GET /content/crm/metrika/report?companyCode=alvi&from=2026-09-01&to=2026-09-24`
требует сессию и `analytics.view` своей компании либо владельца. Настроек и записи
через этот маршрут нет. Произвольный счётчик или адрес API клиент не задаёт.

## Приёмка после подключения

1. Войти владельцем. Открыть сквозную аналитику ALVI и Авокадо по очереди.
2. Сверить счётчик, даты, визиты, посетителей и просмотры с Яндексом за тот же период.
3. Проверить другую компанию: цифры не должны переноситься между проектами.
4. При отсутствии доступа должна быть причина, а не нули или старый успешный отчёт.
5. Проверить обычного аналитика своей компании и отказ для чужой компании.

Без серверного OAuth и успешной живой сверки подключение не считать завершённым.
Доступ Татьяны к аналитике — отдельная настройка прав, этот код её не меняет.
