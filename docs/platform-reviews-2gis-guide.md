# Площадки и отзывы: подтверждённые правила

Дата проверки публичных источников: 17.09.2026.

## Источник данных и открытие площадки

- Сначала читать сохранённую карточку выбранной компании. При недостатке сведений первым внешним источником проверять 2ГИС: название, город и конкретный филиал. Не подменять уже подтверждённые владельцем ссылки найденными значениями.
- Публичная страница компании и кабинет площадки — разные назначения. Кнопка кабинета не подтверждает вход, подключение API или право публикации.
- Ссылки берутся из сохранённого профиля текущей компании. Черновик формы и сведения соседней компании не становятся источником кнопки.
- Разрешены явные HTTPS-ссылки без встроенных логина/пароля и секретных параметров. Значения ключей, токены и ссылки авторизации не выводить в кнопках.
- Общие входы: [2ГИС](https://account.2gis.com/), [Яндекс Бизнес](https://business.yandex.ru/), [ВКонтакте](https://vk.com/), [VK Реклама](https://ads.vk.com/), [Яндекс Директ](https://direct.yandex.ru/), [Telegram Web](https://web.telegram.org/).
- Onlypult использует адрес текущей интеграции [app.ru.onlypult.com](https://app.ru.onlypult.com/). Другой региональный адрес или `my.onlypult.com` автоматически не подставлять.

## Что подтверждено по отзывам

| Площадка | Сейчас подтверждено | Ограничение для Synapse |
| --- | --- | --- |
| 2ГИС | Просмотр и ответы в кабинете компании. | Search API не выдаёт тексты отзывов: `has_reviews` лишь фильтрует организации. Нет подтверждённого публичного контракта отправки ответов. |
| Flamp | Представитель компании может работать с обратной связью на площадке. | Публичный API чтения и ответа не подтверждён; не считать все отзывы Flamp и 2ГИС одним набором. |
| Яндекс Бизнес / Карты | Просмотр владельцем/представителем; ответы через кабинет, до 2500 знаков, затем модерация. | Не обещать API-отправку. API товарных отзывов Яндекс Маркета относится к другому продукту. |
| VK | Официальная схема содержит чтение и создание комментариев стены и обсуждений. | Это не подтверждение API встроенных отзывов с оценками. Нужны конкретный пост/тема и проверенные права отдельного адаптера. |

В ручном процессе хранить источник и URL отзыва, текст и черновик ответа. «Скопировать» и «Открыть площадку» не означают «Отправлено». Отправка на модерацию не означает «Опубликовано»; публикацию подтверждать повторным чтением результата.

## Демонстрация владельца — ожидается

Пользователь покажет свой порядок работы с отзывами и кабинетами. До демонстрации не объявлять подтверждёнными точные административные ссылки филиалов, доступы текущих аккаунтов, правила согласования ответов или способы автоматической отправки. После демонстрации отдельно записать подтверждённые шаги, компанию/филиал и границы разрешённых действий. Само это руководство не запускает ответы или мониторинг.
