# Автосинхронизация контент-плана с Google Таблицей

Задача №193, спецификация `specs/194-google-sheets-sync`. Синхронизация работает без ИИ: обычный серверный таймер и Google API.

## Как это устроено

- **Эталон — ЛК** (решение OD-2026-09-15-COMPANY-TRUTH). Таблица — зеркало для команды.
- Модуль пишет **только** в отдельный лист «Synapse · план». Остальные листы таблицы не читаются и не меняются.
- Колонки листа: `ideaId` (служебный ключ, не менять), `№`, `Дата`, `Тема`, `Формат`, `Площадки`, `Статус`, `Правки/Комментарии`.
- **ЛК → Таблица:** после изменения плана компания встаёт в очередь. Таймер пачкой переписывает только изменённые строки. Раз в сутки ночью (20:00 UTC = 03:00 Бангкок) идёт полная сверка: лист уплотняется и полностью совпадает с ЛК.
- **Таблица → ЛК:** раз в 5 минут сервер спрашивает у Google время последнего изменения таблицы. Если оно новое, читаются только `ideaId`, «Статус» и «Правки/Комментарии». Правки команды приходят в ЛК **предложениями**. План в ЛК сам не меняется: статус меняет человек существующим согласованием.
- **Конфликт:** если строку изменили и в ЛК, и в таблице, в таблицу записывается значение ЛК, а правка из таблицы сохраняется предложением с пометкой «конфликт».
- Если Google недоступен, очередь не теряется: повтор через 30 с, 1, 2, 4 мин… максимум раз в 6 часов.

Ссылка на таблицу берётся из настроек контент-плана компании (поле «Ссылка Google Таблицы»).

## Подключение (делает Влад один раз)

### 1. Создать проект и сервисный аккаунт Google Cloud

1. Откройте https://console.cloud.google.com/ под рабочим Google-аккаунтом.
2. Вверху слева нажмите список проектов → **New project** (Новый проект). Название, например, `synapse-sheets`. Нажмите **Create**.
3. Убедитесь, что вверху выбран этот проект.
4. Меню ☰ → **IAM & Admin** → **Service Accounts** → **+ Create service account**.
5. Имя: `synapse-sheets-sync`. Нажмите **Create and continue**. Роли проекта не нужны — нажмите **Continue**, затем **Done**.
6. На экране появится строка аккаунта с email вида `synapse-sheets-sync@<проект>.iam.gserviceaccount.com`. Скопируйте этот email.

### 2. Включить два API

1. Меню ☰ → **APIs & Services** → **Library**.
2. Найдите **Google Sheets API** → **Enable**. Появится страница API со статусом «API enabled».
3. Вернитесь в Library, найдите **Google Drive API** → **Enable**. Drive нужен только для чтения времени изменения таблицы.

### 3. Дать доступ к таблице

1. Откройте таблицу контент-плана компании.
2. Кнопка **Настройки доступа** (Share) справа вверху.
3. Вставьте email сервисного аккаунта, выберите роль **Редактор**, снимите галочку «Уведомить», нажмите **Отправить**.
4. Повторите для таблицы каждой компании, которую нужно синхронизировать.

### 4. Создать ключ и положить его в секреты сервера

1. **IAM & Admin** → **Service Accounts** → нажмите на `synapse-sheets-sync` → вкладка **Keys**.
2. **Add key** → **Create new key** → **JSON** → **Create**. Браузер скачает файл `.json`.
3. Содержимое файла целиком (одной строкой JSON) положите в секреты сервера как переменную `GOOGLE_SHEETS_SA_JSON`.
4. Файл ключа не отправляйте в чаты, не кладите в репозиторий и не прикрепляйте к задачам. После сохранения в секретах удалите его с компьютера.
5. Перезапустите сервер, чтобы он увидел переменную.

## Признак готовности

- Статус модуля (`status(companyCode)`) показывает `connected: true` и email сервисного аккаунта. Без ключа — `connected: false` и причина «переменная GOOGLE_SHEETS_SA_JSON не задана».
- В таблице компании появился лист **«Synapse · план»** с заголовком из восьми колонок и строками плана.
- Измените тему публикации в ЛК — в течение минуты меняется только эта строка листа.
- Поменяйте «Статус» в листе — в течение 5–6 минут в ЛК появляется предложение от источника `google-sheet`, а сам план не меняется до решения человека.

## Частые ошибки

| Что видно в статусе | Причина | Что сделать |
|---|---|---|
| `NOT_CONNECTED` | Нет переменной или ключ испорчен | Повторить шаг 4 |
| `Google API 403` | Таблице не дан доступ или API не включён | Шаги 2 и 3 |
| `Google API 404` | Ссылка в настройках ведёт на другую или удалённую таблицу | Проверить ссылку в настройках контент-плана |
| `Google API 429` | Превышена квота Google | Ничего: очередь повторит позже |

## Что ещё не сделано

Модуль написан и проверен тестами, но **не подключён** к серверу. Следующий этап: регистрация таймера и постановка в очередь при изменении плана в `server.js`, приём предложений в существующий поток согласования, кнопка «Синхронизировать сейчас» и статус в настройках контент-плана.
