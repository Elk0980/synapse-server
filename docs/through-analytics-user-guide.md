# Как пользоваться сквозной аналитикой

В личном кабинете выберите нужную компанию и откройте «Сквозная аналитика». Компании проверяйте отдельно. Инструкция также раскрывается на самой странице аналитики.

## Первый просмотр

1. Выберите даты «С» и «По». Вчера подходит для ежедневного контроля, две полные недели одинаковой длины — для сравнения. Сегодня ещё не завершилось. Для «всего времени» укажите начало фактически доступной истории: новый счётчик не восстанавливает посещения старого сайта.
2. Проверьте последний успешный сбор Метрики и YCLIENTS. Отказ загрузки или отсутствующее подключение означает «неизвестно», а не ноль. Ручная статистика 2ГИС обновляется отдельно.
   В таблице «Можно ли доверять показателям» прочитайте причины: старый снимок, неполная история, выборка, неизвестные источники или связи оплат. «Нет событий в снимке» отличается от «Пока неизвестно». После смены правил YCLIENTS деньги появятся после новой успешной выгрузки. «Проверено по снимку» относится только к указанной проверке; это не подтверждение окупаемости рекламы.
3. Просмотрите путь: сайт → действие → подтверждённая запись → состоявшееся посещение → оплата. Клик на кнопку записи показывает намерение, но не созданную запись. Клик на телефон не подтверждает разговор.
4. В таблице целей прочитайте каждое действие отдельно. Целевые визиты — визиты с действием; достижения — выполнения, включая повторные. Один человек может выполнить несколько целей. Число настроенных целей и сумма их достижений не равны клиентам.
5. В YCLIENTS проверьте отмены, неявки, платежи, возвраты, записи без источника и операции без связи с записью. Не складывайте данные Метрики и YCLIENTS как независимых клиентов.

## Основные показатели

| Показатель | Что он отвечает |
|---|---|
| Визиты / посетители | Сколько посещений сайта / уникальных посетителей было в выбранном периоде |
| Среднее время | Как долго в среднем длился визит; само по себе не доказывает качество или продажу |
| Конверсия конкретной цели | Доля визитов, в которых произошло выбранное действие |
| Подтверждённые записи | Сколько записей создано; отмены учитываются отдельно |
| Состоявшиеся посещения | Сколько посещений действительно состоялось |
| Платящие клиенты | Уникальные клиенты с подтверждёнными положительными платежами; это не обязательно новые клиенты |
| Денежный итог | Платежи минус возвраты; прибыль требует учёта себестоимости |
| Покрытие источников | Какая доля записей имеет источник; неизвестные строки остаются неизвестными |
| CAC | Расходы на привлечение / новые платящие клиенты одной и той же группы |
| ROMI | (Маржинальный доход этой группы − маркетинговые расходы) / маркетинговые расходы × 100% |

CAC и ROMI нельзя считать при неполных расходах, неизвестных первых оплатах/источниках или себестоимости. «—» в таком случае не означает нулевую стоимость клиента. При нулевых расходах процент окупаемости не определён.

Создание записи, посещение и оплата имеют разные даты. Отношение их календарных итогов не является конверсией одной группы: запись могла быть создана раньше и оплачена позже. Для оценки рекламы нужна группа клиентов, привлечённых выбранным источником в выбранный период, и заданный срок наблюдения за их оплатами.

## Источники и 2ГИС

Фильтр площадок относится к общей воронке. Блок «Записи и оплаты из источников» показывает компанию целиком. Проверяйте заголовок блока, даты и подпись источника.

UTM показывают метку перехода, а не поисковую фразу. Метка рекламной ссылки не доказывает, что именно реклама вызвала покупку. Поиски по названию и услугам можно разделять только там, где сама площадка предоставляет такие данные; их доли нельзя переносить на визиты сайта без связи между событиями.

## Рабочий ритм

Ежедневно за пять минут: свежесть → визиты → подтверждённые записи → состоявшиеся посещения → платежи и возвраты → неизвестные источники. Если данных нет, проверьте подключение вместо вывода «клиентов не было».

Раз в неделю: сравните две полные недели одинаковой длины, посмотрите каждый источник, проверьте расходы и новые оплаты. Выберите одно улучшение по самому заметному месту потери клиентов. Изменения текста и дизайна сайта согласовываются отдельно.

При обращении за помощью сообщите компанию, даты отчёта, время последнего успешного обновления и видимую ошибку. Не отправляйте ключи доступа и личные данные клиентов.
