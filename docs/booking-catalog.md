# Проверенное предложение в записи на визит

В карточке CRM администратор может выбрать услугу из текущего проверенного каталога своей компании. Существующие права `crm.edit` и `company-information.view` обязательны; новые роли и разрешения не выдаются.

Форма передаёт только `serviceSelection: {id, knowledgeRevision}` вместе с событием `booked`. Цена, валюта, количество процедур и текст заново берутся сервером из подтверждённых сведений внутри транзакции записи. При изменении каталога — 409, при неподтверждённой услуге — отказ. Подставить цену через форму нельзя.

В событии сохраняется снимок предложения. Изменение прайса не переписывает историю, перенос сохраняет те же условия, отмена ошибочной отметки восстанавливает предыдущую запись. Новая запись без выбора не наследует услугу старого визита. Цена курса остаётся полной ценой курса, без деления на процедуры.

Для прежних записей и услуг вне проверенного каталога сохранена запись без привязки; она не создаёт подтверждённую цену. Выбор услуги не проверяет свободные окна, не подтверждает оплату и не отправляет сообщение клиенту. Время и договорённости подтверждает администратор.

Это подключение каталога к рабочей карточке администратора. Автоматический переход из диалога клиентского бота в CRM, выбор времени и ответ клиенту пока требуют отдельной интеграции. Реальный каталог и подключение ALVI должны быть подтверждены отдельно.
