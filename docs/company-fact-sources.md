# Источники сведений компании

Раздел «Актуальность» сохраняет значения в прежней карточке компании. Под ней
добавлена проверка источников отдельных фактов: контактов, домена, описания,
каждой цены, длительности, условия акции и ссылки на материал.

## Поведение

- Существующее значение импортируется без заявления о проверенном источнике.
- Источник содержит название, ссылку либо точное обозначение документа, дату
  проверки и необязательное пояснение. Ссылка отображается текстом; система
  не открывает её и не исполняет инструкции из неё.
- Подтверждение относится к конкретной версии значения. Изменение или удаление
  создаёт новую неподтверждённую запись, связанную с предыдущей через supersedesId.
- История неизменяема, содержит прежние значения, источники и проверяющего.
- Услуги, акции и материалы адресуются по их ID. Перестановка не теряет источники.
  Старые ссылки CRM без ID адресуются по позиции; перестановка изменившихся строк
  требует повторной сверки. Переименование услуги также требует повторной сверки.
- Пустые значения и удаления тоже можно подтвердить документом. Наличие записи
  без источника не является доказательством актуальности.

## Сохранение и права

Прежний PUT `/company-information?companyCode=...` принимает дополнительный массив
`factConfirmations`: `{factId, source, sourceRef, checkedAt, note}`. Дата — UTC.
Для отдельного подтверждения передают текущую revision и пустой profile.
Такое подтверждение не меняет версию содержимого компании и не останавливает
уже согласованные публикации. Конкурирующие подтверждения защищены текущим factId.
Изменение профиля и подтверждения в одном запросе атомарны; нельзя подтвердить
старый factId одновременно с заменой его значения. Чужой либо устаревший ID
отклоняется. Будущие даты, пустые источники и повторные ID отклоняются.

GET карточки возвращает `facts` — текущие версии, включая удаления.
GET `/company-information/facts?companyCode=...&key=...` возвращает последние
100 версий конкретного факта. Действуют существующие company-information.view/edit,
привязка к компании, доверенная identity и CSRF кабинета. Новых прав нет.

`fieldStates` сохраняет прежнюю совместимость редакторского учёта; это не источник
для доказательства проверенности. Для источников используется `facts[].status`.
Само сохранение текста владельцем не доказывает проверку внешнего документа.

## Границы

Документы не распознаются и противоречия не разрешаются автоматически. Источник
вносит проверяющий. Обработчики ответов бота должны отдельно использовать актуальные
версии и не трактовать unverified как confirmed. Эта доработка не включает такой
переход всех обработчиков и не подтверждает заполнение реальных прайсов компаний.

## Проверки

`node --test ops/crm/company-facts.test.js ops/crm/company-information.test.js`

`node --test sites/synapse/cabinet/company-information.test.cjs` (jsdom)

Проверены смена цены, удаление, перестановка услуг, неизменяемость истории,
изоляция компаний, откат ошибочного пакета, конфликт версий, местное время формы,
сохранение несохранённого ввода и безопасный вывод текста источников.
