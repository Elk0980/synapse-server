# Импорт проверенных услуг

В разделе «Актуальность» есть проверка JSON-файла, предпросмотр компании/цен/количества/источников и отдельное добавление после отметки сверки. Выбор файла не сохраняет каталог.

Формат файла:

```json
{
  "companyCode": "example",
  "clientImportId": "price-20260929-v1",
  "entries": [{
    "service": {"id": "massage-five", "title": "Массаж", "price": 15000, "currency": "RUB", "procedureCount": 5, "durationMinutes": 60},
    "source": "Прайс компании",
    "sourceRef": "Документ от 29 сентября, строка 1",
    "checkedAt": "2026-09-29T05:00:00.000Z"
  }]
}
```

Это пример формата, не клиентские цены. `durationMinutes` описывает одну процедуру. Неизвестную длительность не заполнять. Каждая строка получает источники всех своих непустых полей; файл должен быть заранее сверенным, импорт не выполняет OCR и не доказывает истинность его содержимого.

`POST /company-information/catalog-preview` и `POST /company-information/catalog-import` принимают этот объект с `revision` текущего профиля. Требуются прежние права редактирования компании, доверенная личность и CSRF в кабинете. Компания файла должна точно совпадать с выбранной.

Импорт добавляет строки, сохраняет прочие услуги и поля. Другие значения при существующем ID дают конфликт; нет скрытого удаления или замены. Запись каталога, подтверждений источников и квитанции выполняется одной транзакцией. Повтор по `clientImportId` с тем же содержимым возвращает текущий профиль и `duplicate:true`, даже после последующих ручных правок; старое содержимое не восстанавливается. Другой файл с тем же ID отклоняется. Новая версия профиля требуется для первого применения, но не для повтора уже завершённого импорта.

Максимум 200 услуг в итоговом каталоге, 200 КБ профиля. Акции, сроки действия курсов и доступность записи не придумываются. Импорт не отправляет сообщения и не включает клиентского бота. Изменение содержимого каталога использует прежнюю остановку устаревших публикаций; повтор или подтверждение источников без нового содержимого её не вызывает.
