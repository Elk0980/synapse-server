## Блокер точного переноса

[Официальная документация Timeweb](https://timeweb.cloud/docs/cloud-servers/manage-servers/console)
описывает выделение текста и CtrlShiftC. На доступном инструменте выделение
свежего короткого числа видно, но clipboard после CtrlShiftC остался исходным.
Дополнительный нативный инструмент остановился ещё при инициализации с
`failed to write kernel assets … os error 3`; UI-действий через него не было.
Открытых SFTP-клиентов и кнопок download/filetransfer не обнаружено.
Старый scrollback и содержимое буфера не копировались/не выводились.

Для продолжения нужен утверждённый read-only канал точного экспорта безопасных
файлов и списка отличий либо соответствующий комплект от Claude. Переносить
исходники через OCR или объявлять public main реальным сервером нельзя.
На сервере выполнялось только чтение; файлов, архивов и новых release-скриптов
не создавали, сервисы/права/защиту не меняли.
