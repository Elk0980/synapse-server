# Проверка аналитики ALVI

Из корня репозитория: `node --test sites/alvi/analytics-tests/*.test.cjs`.
Нужен `jsdom` в окружении Node (допускается внешний каталог через `NODE_PATH`).
Сеть и реальные заявки в этих тестах не используются.

Новая заявка — только HTTP 201, положительный целый `id` и отсутствие признака
дубля. Повторная заявка и ошибка имеют отдельные цели. Просмотры этапов требуют
реальной видимости; открытый встроенный прайс передаёт события родителю, не
создавая второй счётчик. Параметры целей не содержат значений полей формы.

В Метрике последовательную воронку формы следует настраивать составной целью:
`callback_start` → `callback_attempt` → `callback_submit`.
Независимые `service_view`, `price_view`, `contact_view`, `callback_open`
не образуют упорядоченную воронку сами по себе. Новые цели не восстанавливают
исторические события. Клики по контактам и записи не доказывают разговор или оплату.
