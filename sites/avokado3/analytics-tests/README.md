# Проверка аналитики Авокадо

Из корня репозитория:

```text
node sites/avokado3/analytics-tests/analytics-check.cjs
node --test sites/avokado3/analytics-tests/analytics-dom.test.cjs
```

DOM-тестам нужен `jsdom` в окружении Node (можно через внешний `NODE_PATH`).
Используется реальная разметка и код сайта; геометрия, загрузка каталога и
доставка `postMessage` эмулируются, поскольку jsdom не исполняет layout.
Реальные заявки и запросы в Яндекс не отправляются.

В Метрике последовательная составная цель формы:
`callback_start` → `callback_attempt` → `callback_submit`.
Успех — HTTP 201 и положительный целый идентификатор новой заявки, дубли и ошибки
учитываются отдельно. Просмотры этапов считаются только после фактического показа.
Прайс в iframe передаёт просмотр и клики одному родительскому счётчику.
Значения имени, телефона и комментария в цели не передаются.

Просмотры услуг, прайса и контактов — независимые события, их разность не является
потерей между последовательными шагами. Клик записи — не подтверждённая запись.
Новые цели не заполняются задним числом. Вебвизор остаётся выключенным в коде,
согласно действующей политике сайта.
