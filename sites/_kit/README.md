# Общий набор деталей сайтов (site kit)

Правка, сделанная однажды, действует на всех подключённых сайтах; новый сайт собирается
с учётом прежних правок. Спецификация: `specs/097-site-kit`.

## Что внутри

| Файл | Что делает |
|---|---|
| `select.css` | Выпадающий список в стиле сайта: без системного вида (`appearance: none`), своя стрелка, фокус, disabled. Работает без JS. |
| `select.js` | На устройствах с мышью строит список в стиле сайта (`role=combobox` + `listbox`, клавиатура: стрелки, Home/End, Enter/Space, Escape, Tab, набор буквы). Нативный `<select>` остаётся в форме: имя, значение, `required`, `change`. На телефоне — системный список, оформлен только контрол. |
| `fields.css` | Поля, textarea, флажки (`accent-color`), фокус, ошибка `:user-invalid`. Всё в `:where()` — правила сайта важнее. |
| `sites.json` | Какие сайты подключены, куда копировать, тема сайта (переменные `--kit-*`), какие сайты отложены и почему. |
| `index.html` | Демо с тремя палитрами. Не публикуется (ни один домен не раздаёт `sites/_kit`), `noindex`. |

## Почему копии, а не одна общая папка

Caddy раздаёт каждый сайт изолированно (`root * /srv/sites/<сайт>`), путь `../_kit` с домена
сайта недоступен. Поэтому `tools/site-kit/sync.js` копирует файлы в `sites/<сайт>/assets/kit/`
и ставит `?v=<хеш>` в подключения. Тест `sites/site-kit.test.cjs` падает, если копия
разошлась с источником, если на странице с `<select>` kit не подключён или если новый сайт
с `<select>` не внесён в `sites.json`.

## Как править

1. Изменить файл в `sites/_kit/` (не копию в сайте).
2. `node tools/site-kit/sync.js` — обновит копии и версии во всех подключённых сайтах.
3. `node --test sites/site-kit.test.cjs` (нужен jsdom в `NODE_PATH`).
4. Посмотреть скриншоты: `node tools/site-kit/screenshots.js --out <каталог вне git> --all-sites`
   и поведение в браузере: `node tools/site-kit/browser-check.js --site <сайт>` (нужен Playwright).
   CI workflow `site-kit` делает то же и прикладывает скриншоты артефактом.

## Как подключить новый сайт

Добавить сайт в `sites.json → sites` с темой и запустить `sync.js`. Он сам вставит на каждую
страницу с `<select>` после последней таблицы стилей сайта:
`theme.css`, `fields.css`, `select.css` и `select.js` (defer). Контент страниц не меняется.

## Переменные темы

| Переменная | Запас | Смысл |
|---|---|---|
| `--kit-bg` | `#fff` | фон контрола и списка |
| `--kit-fg` | `inherit` | текст |
| `--kit-muted` | `inherit` | подписи групп, placeholder |
| `--kit-border` | `currentColor` | рамка |
| `--kit-border-width` | `1px` | толщина рамки |
| `--kit-accent` | `currentColor` | рамка при наведении, фокус, флажки |
| `--kit-accent-soft` | смесь accent 18% | подсветка активного пункта |
| `--kit-arrow` | `--kit-accent` | цвет стрелки |
| `--kit-radius` | `8px` | скругление |
| `--kit-font` | `inherit` | шрифт |
| `--kit-pad-x`, `--kit-pad-y` | `12px`, `10px` | внутренние отступы |
| `--kit-control-height` | `44px` | минимальная высота (палец) |
| `--kit-shadow`, `--kit-danger`, `--kit-z` | — | тень списка, цвет ошибки, z-index |

Отказ от kit на конкретном списке: `data-kit-native` на `<select>` или его контейнере.
Принудительно свой список даже на телефоне: `data-kit-custom`.
